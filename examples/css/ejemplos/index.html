Tipos de CSS
CSS puede aplicarse de tres formas: inline en el atributo style, interno dentro de <style> en el <head>, y externo en un archivo .css separado.

Selectores CSS
Los selectores determinan a qué elementos HTML se aplican las reglas CSS. Existen selectores de elemento, clase, ID, pseudo-clases, pseudo-elementos y combinadores.
Vista previa

Selector de elemento

p { color: green }

Selector de clase (.)

.card
.card
.card

Selector ID (#)

#header — único
CSS 
/* ── Selector de elemento: afecta a TODOS los <p> ── */
p {
  color: #34495e;
  line-height: 1.6;
}

/* ── Selector de clase: reutilizable en múltiples elementos ── */
.card {
  background: white;
  border-radius: 8px;
  padding: 20px;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}

/* ── Selector de ID: solo un elemento por página ── */
#header {
  background: linear-gradient(135deg, #667eea, #764ba2);
  color: white;
}

/* ── Múltiples clases en un elemento ── */
/* HTML: <button class="btn btn-primary"> */
.btn            { padding: 10px 20px; border-radius: 5px; }
.btn-primary    { background: #667eea; color: white; }
.btn-secondary  { background: #6c757d; color: white; }

Elementop, h1, div0,0,0,1En todos los elementos del tipo
Clase.nombre0,0,1,0✅ En múltiples elementos
ID#nombre0,1,0,0❌ Solo un elemento

li:not(.especial) { opacity: 0.6; }

/* :where() — igual a :is() pero sin especificidad */
:where(section, article) p { line-height: 1.8; }
Tipos de combinadores
A > B Hijo directo .nav > li
A + B Hermano adyacente h2 + p
A ~ B Hermanos generales h2 ~ p
A B Descendiente (cualquier nivel) .card p
CSS 
/* Espacio: descendiente a cualquier nivel */
.card p { color: #555; }

/* > : solo hijo DIRECTO */
nav > ul > li { display: inline-block; }

/* + : hermano INMEDIATAMENTE siguiente */
h2 + p { font-size: 1.1rem; color: #666; }

/* ~ : TODOS los hermanos siguientes */
h2 ~ p { border-left: 3px solid #667eea; padding-left: 10px; }

/* Combinación múltiple */
.section > .card > h3 + p {
  margin-top: 0;
  color: var(--muted);
}

03
Box Model
Cada elemento HTML es una caja rectangular compuesta por content → padding → border → margin. La propiedad box-sizing controla cómo se calculan las dimensiones totales.
Diagrama del Box Model
margin
border
padding
content
width × height
content padding border margin
CSS 
.caja {
  /* Dimensiones del contenido */
  width:  300px;
  height: 150px;

  /* Padding: espacio INTERNO (entre content y border) */
  padding: 20px;            /* todos los lados */
  padding: 10px 20px;       /* vertical | horizontal */
  padding: 5px 10px 15px 20px; /* top right bottom left */
  padding-top: 10px;        /* lado individual */

  /* Border: borde visible */
  border: 2px solid #3498db;
  border-radius: 8px;        /* esquinas redondeadas */

  /* Margin: espacio EXTERNO (entre elementos) */
  margin: 20px;
  margin: 0 auto;            /* centrar horizontalmente */

  /* outline: no afecta el layout (útil para debug) */
  outline: 2px dashed red;
}
💡 Truco de debug Agrega * { outline: 1px solid red; } temporalmente para visualizar todas las cajas del layout.
content-box vs border-box

content-box (por defecto)

width=180px solo es el contenido.
Total = 180 + 32(padding) + 16(border) = 228px

border-box ✅ recomendado

width=180px ya incluye padding + border.
Total = 180px
CSS 
/* Reset universal recomendado */
*,
*::before,
*::after {
  box-sizing: border-box; /* width incluye padding + border */
}

/* content-box (default): width = SOLO contenido */
.content-box {
  box-sizing: content-box;
  width: 200px;
  padding: 20px;
  border: 5px solid;
  /* Ancho real = 200 + 40(padding) + 10(border) = 250px */
}

/* border-box: width = contenido + padding + border */
.border-box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid;
  /* Ancho real = 200px (siempre) */
}

04
Propiedad Display
La propiedad display define cómo se renderiza un elemento y cómo interactúa con los demás en el flujo del documento.
Comportamiento según display

display: block — ocupa todo el ancho disponible

div.block (100% ancho)

display: inline — solo ocupa lo necesario, fluye con el texto

Texto normal span inline continúa el texto otro inline en la misma línea.

display: inline-block — fluye inline pero acepta width/height

100px 140px 80px

display: none — elimina el elemento del flujo (invisible + sin espacio)

Este elemento no se ve ⟵ El elemento oculto no ocupa espacio aquí
CSS 
/* block: nueva línea, 100% ancho por defecto */
div, p, h1, section { display: block; }

/* inline: fluye con el texto, NO acepta width/height */
span, a, strong { display: inline; }

/* inline-block: fluye inline pero SÍ acepta width/height */
.badge {
  display: inline-block;
  width: 80px;
  padding: 6px 12px;
  text-align: center;
}

/* none: oculta y saca del flujo del documento */
.hidden { display: none; }

/* visibility: hidden — oculta pero mantiene el espacio */
.invisible { visibility: hidden; }

/* flex y grid — ver secciones 10 y 11 */
.flex-container { display: flex; }
.grid-container { display: grid; }

inline❌❌✅
inline-block❌✅✅
none——❌
flex✅ (container)✅✅
grid✅ (container)✅✅

Posicionamiento
La propiedad position controla cómo se ubica un elemento en la página. Las propiedades top, right, bottom y left definen el desplazamiento según el contexto de posicionamiento.
static vs relative

position: static (por defecto)

Caja A
Caja B (flujo normal)

position: relative — desplaza desde su posición original

Caja A
Caja B (top:-6 left:16)
CSS
/* static: posición normal en el flujo (valor por defecto) */
.caja { position: static; } /* top/left/etc NO tienen efecto */

/* relative: se desplaza DESDE su posición original */
.desplazada {
  position: relative;
  top:  -10px;  /* sube 10px */
  left: 20px;   /* mueve 20px a la derecha */
  /* Su espacio original en el flujo se PRESERVA */
}

/* relative como contenedor para hijos absolute */
.card {
  position: relative; /* crea el contexto de posicionamiento */
}
position: absolute
NUEVO -30%
Contenedor con position: relative
Los badges usan position: absolute
CSS
/* absolute: sale del flujo, se posiciona respecto */
/* al ancestro más cercano con position != static */
.tarjeta {
  position: relative;   /* contenedor de referencia */
}

.badge-esquina {
  position: absolute;
  top:   8px;
  right: 8px;
  /* No ocupa espacio en el flujo */
}

/* fixed: como absolute pero respecto al VIEWPORT */
.nav-fijo {
  position: fixed;
  top:   0;
  left:  0;
  right: 0;
  z-index: 100;  /* encima del contenido */
}

/* Centrar absolutamente */
.centrado {
  position: absolute;
  top:       50%;
  left:      50%;
  transform: translate(-50%, -50%);
}
💡 sticky: lo mejor de relative + fixed El elemento se comporta como relative hasta que el scroll lo alcanza — entonces se "pega" como fixed. La barra de navegación de esta guía usa position: sticky.
CSS
/* sticky: combina relative y fixed según el scroll */
nav {
  position: sticky;
  top: 0;        /* se pega cuando llega a y=0 */
  z-index: 100;
}

/* Encabezado de tabla sticky */
thead tr th {
  position: sticky;
  top: 0;
  background: white;
}

/* Sidebar sticky */
.sidebar {
  position: sticky;
  top: 80px;  /* debajo del nav */
  height: fit-content;
}

06
Unidades CSS
CSS ofrece unidades absolutas (valor fijo) y relativas (proporcionales al contexto). Las relativas son clave para el diseño responsive y accesible.
Tamaños absolutos (no cambian)
96px
1cm
CSS
/* Unidades absolutas — valor fijo independiente del contexto */
.elemento {
  width:  200px;   /* píxeles — la más usada en pantalla */
  width:  5cm;    /* centímetros */
  width:  2in;    /* pulgadas */
  width:  20mm;   /* milímetros */
  width:  12pt;   /* puntos (1pt = 1/72 in) — tipografía print */
  width:  1pc;    /* picas (1pc = 12pt) */
}
⚠ Nota El pixel CSS (px) no es un pixel de pantalla físico. En pantallas Retina, 1px CSS = 2 píxeles físicos.
em vs rem
Padre: 20px → 1.5em = 30px rem siempre = relativo al root (16px por defecto) 1.5rem = 24px
CSS
/* em: relativo al font-size del PADRE */
.padre   { font-size: 20px; }
.hijo    { font-size: 1.5em; }  /* = 30px */
.nieto   { font-size: 1.5em; }  /* = 45px — se acumula! */

/* rem: siempre relativo al font-size del <html> (root) */
html      { font-size: 16px; }   /* base */
.cualquier { font-size: 1.5rem; } /* = 24px siempre */

/* % : relativo al padre */
.hijo { width: 50%; }   /* 50% del ancho del padre */

/* ch: ancho del carácter "0" — útil para límites de texto */
p { max-width: 65ch; }

/* ex: altura de la letra "x" */
.icono { height: 2ex; }
Unidades relativas al viewport
100vw = 100% del ancho del viewport
50vw = 50% del ancho del viewport
svh / dvh / lvh — viewport altura en mobile
CSS
/* vw / vh — porcentaje del viewport */
.hero {
  width:      100vw;  /* 100% ancho del viewport */
  min-height: 100vh;  /* 100% altura del viewport */
}

/* svh/dvh/lvh — alturas dinámicas para mobile */
.pantalla-movil {
  min-height: 100dvh;  /* dynamic viewport height */
}

/* vmin / vmax */
.cuadrado-adaptable {
  width:  50vmin;  /* 50% del lado más pequeño */
  height: 50vmin;
}

/* cqi / cqb — container query units (CSS moderno) */
.componente {
  font-size: 4cqi;  /* 4% del ancho del container */
}

07
Colores en CSS
CSS soporta múltiples formatos de color: nombres de color, hexadecimal, RGB, HSL y sus variantes con canal alfa para transparencia.
Misma paleta — distintos formatos
nombre: color: dodgerblue
hex: color: #3498db
rgb: color: rgb(52, 152, 219)
rgba: color: rgba(52, 152, 219, 0.5)
hsl: color: hsl(204, 70%, 53%)
hsl+alfa: color: hsl(204 70% 53% / 0.5)
CSS
.colores {
  /* Nombre CSS (140 nombres predefinidos) */
  color: dodgerblue;
  color: tomato;
  color: mediumseagreen;

  /* Hexadecimal: #RRGGBB o #RGB (shorthand) */
  color: #3498db;
  color: #3df;         /* = #33ddff */
  color: #3498dbcc;   /* con alfa (80% opacidad) */

  /* RGB / RGBA */
  color: rgb(52, 152, 219);
  color: rgba(52, 152, 219, 0.6); /* alfa: 0=transparente, 1=sólido */
  color: rgb(52 152 219 / 60%);   /* sintaxis moderna */

  /* HSL: Hue Saturation Lightness */
  color: hsl(204, 70%, 53%);       /* matiz 204°, sat 70%, luz 53% */
  color: hsl(204 70% 53% / 0.5);  /* con transparencia */

  /* oklch — espacio perceptual moderno (CSS Color 4) */
  color: oklch(65% 0.2 250);
}
Tipos de gradientes
linear-gradient(135deg, #667eea, #764ba2)
radial-gradient(circle, #f093fb, #f5576c)
conic-gradient(...)
CSS
/* Gradiente lineal */

}

/* Radial (desde el centro) */

  background: radial-gradient(circle at center, #f093fb, #f5576c);
}

/* Cónico (tipo torta) */

  background: conic-gradient(#58a6ff 0% 30%, #3fb950 30% 70%, #ffa657 70% 100%);

/* Texto con gradiente */
.titulo-gradiente {
  background: linear-gradient(135deg, #e6edf3, #58a6ff);
  -webkit-background-clip: text;

  background-clip: text;

Demo: tema dinámico con variables

Título con --demo-color

Botón primario
Botón outline
CSS

:root {
  --color-primario: #3498db;

  --espacio-md:     1rem;
  --radio:          8px;
  --sombra:         0 4px 12px rgba(0,0,0,0.15);

.boton {

  box-shadow:    var(--sombra);

.elemento {

09
Tipografía
CSS controla todos los aspectos del texto: familia tipográfica, tamaño, peso, interlineado, espaciado, alineación y mucho más.
Propiedades tipográficas en acción
font-weight: 800
font-style: italic, weight: 400
letter-spacing: 0.15em — text-transform: uppercase
line-height: 2 — Este párrafo tiene un interlineado de 2, lo que significa que hay mucho espacio vertical entre líneas, mejorando la legibilidad en bloques de texto largos.
text-decoration: underline — text-underline-offset: 4px
CSS
body {
  /* Stack de fuentes: de preferida a genérica */
  font-family: 'Inter', 'Segoe UI', Helvetica, Arial, sans-serif;
  font-size:   16px;       /* base */
  line-height: 1.6;        /* sin unidad: relativo al font-size */
  color:       #1c1c1e;
}

h1 {
  font-size:      clamp(1.8rem, 4vw, 3rem); /* fluido */
  font-weight:    800;
  line-height:    1.2;
  letter-spacing: -0.03em; /* kerning negativo en títulos */
}

p {
  max-width:   65ch;       /* límite legible */
  text-align:  left;       /* left | center | right | justify */
  hyphens:     auto;       /* separación silábica */
}

.codigo {
  font-family:  'Fira Code', 'Consolas', monospace;
  font-size:    0.875em;
}

/* Carga de fuentes de Google Fonts */
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;600;800&display=swap');

/* Fuente local con @font-face */
@font-face {
  font-family: 'MiFuente';
  src: url('fuentes/mifuente.woff2') format('woff2');
  font-weight: 400 700;   /* rango de pesos */
  font-display: swap;     /* evita FOIT */
}

CSS — Contenedor Flex
.flex-container {
  display: flex;

  /* Dirección del eje principal */
  flex-direction: row;            /* row | row-reverse | column | column-reverse */

  /* Distribución en el eje principal */
  justify-content: flex-start;   /* flex-start | center | flex-end
                                       space-between | space-around | space-evenly */

  /* Alineación en el eje secundario */
  align-items: stretch;          /* stretch | flex-start | center | flex-end | baseline */

  /* Alineación de múltiples líneas */
  align-content: flex-start;     /* cuando hay flex-wrap */

  /* Permitir que los ítems salten a la siguiente línea */
  flex-wrap: wrap;               /* nowrap | wrap | wrap-reverse */

  /* Shorthand: direction + wrap */
  flex-flow: row wrap;

  /* Espacio entre ítems */
  gap: 1rem;                      /* row-gap column-gap */
}

CSS — Ítems Flex
.flex-item {
  /* flex-grow: cuánto crece respecto a otros (0 = no crece) */
  flex-grow: 1;

  /* flex-shrink: cuánto se encoge (0 = no se encoge) */
  flex-shrink: 1;

  /* flex-basis: tamaño base antes de distribuir espacio */
  flex-basis: 200px;

  /* Shorthand: grow shrink basis */
  flex: 1 1 200px;
  flex: 1;          /* = 1 1 0 */
  flex: auto;       /* = 1 1 auto */
  flex: none;       /* = 0 0 auto */

  /* align-self: sobreescribe align-items del contenedor */
  align-self: center; /* auto | flex-start | center | flex-end | stretch */

  /* order: cambia el orden visual (no el del DOM) */
  order: -1;           /* va al inicio */
}

CSS
.grid-container {
  display: grid;

  /* Definir columnas */
  grid-template-columns: repeat(3, 1fr);      /* 3 columnas iguales */
  grid-template-columns: 200px 1fr 1fr;        /* mixta */
  grid-template-columns: repeat(4, minmax(200px, 1fr));

  /* Definir filas */
  grid-template-rows: auto 1fr auto;          /* header / content / footer */

  /* Separación */
  gap: 1rem;             /* row-gap + column-gap */
  row-gap: 1rem;
  column-gap: 1.5rem;
}

/* Controlar posición/tamaño de ítems */
.item-span {
  grid-column: span 2;    /* ocupa 2 columnas */
  grid-row:    span 2;    /* ocupa 2 filas */
}

.item-posicion {
  grid-column: 2 / 4;    /* de línea 2 a línea 4 */
  grid-row:    1 / 3;
}

El diseño responsive adapta la interfaz a distintos tamaños de pantalla usando media queries, unidades fluidas, imágenes adaptables y el enfoque mobile-first.

CSS — Media Queries
/* ── Sintaxis básica ── */
@media (max-width: 768px) {
  .sidebar { display: none; }
  .columnas { grid-template-columns: 1fr; }
}

/* ── Mobile First (recomendado) ── */
/* Estilos BASE = mobile */
.card-grid {
  display: grid;
  grid-template-columns: 1fr;      /* 1 columna en mobile */
  gap: 1rem;
}

/* Tablet ≥768px */
@media (min-width: 768px) {
  .card-grid { grid-template-columns: repeat(2, 1fr); }
}

/* Desktop ≥1024px */
@media (min-width: 1024px) {
  .card-grid { grid-template-columns: repeat(3, 1fr); }
}

/* ── Condiciones múltiples ── */
@media (min-width: 768px) and (max-width: 1024px) { /* solo tablet */ }
@media (orientation: landscape) { /* solo landscape */ }
@media (prefers-color-scheme: dark) { /* modo oscuro del OS */ }
@media (prefers-reduced-motion: reduce) { /* sin animaciones */
  * { animation: none !important; transition: none !important; }
}

Funciones Modernas CSS
CSS cuenta con funciones matemáticas (calc, clamp, min, max) y otras utilidades modernas que permiten cálculos dinámicos sin JavaScript.
calc() — mezcla unidades
width: calc(100% - 64px) — ancho completo menos un margen fijo
CSS
/* calc() puede mezclar cualquier unidad CSS */
.sidebar-layout {
  width: calc(100% - 280px);       /* % - px */
}

.full-bleed {
  margin-left:  calc(-1 * var(--padding));
  margin-right: calc(-1 * var(--padding));
}

.nav-content {
  min-height: calc(100vh - 60px);  /* pantalla - nav */
}

/* Operaciones permitidas: + - * / */
.grid-gap {
  /* IMPORTANTE: dejar espacios alrededor de + y - */
  width: calc(33.333% - 1rem);
  width: calc(2rem * 4);
  width: calc(100% / 3);
}
clamp(mínimo, ideal, máximo) — valor fluido
clamp(1rem, 4vw, 2.5rem)

↑ Este texto escala fluidamente entre 1rem y 2.5rem según el ancho del viewport.

CSS
/* clamp(MIN, IDEAL, MAX) */
/* = max(MIN, min(IDEAL, MAX)) */

/* Tipografía fluida — escala con el viewport */
h1 { font-size:  clamp(1.75rem, 5vw, 3.5rem); }
h2 { font-size:  clamp(1.25rem, 3vw, 2rem); }
p  { font-size:  clamp(1rem, 1.5vw, 1.2rem); }

/* Ancho fluido con límites */
.container {
  width: clamp(320px, 90%, 1200px);
  /* mínimo 320px, máximo 1200px, ideal 90% */
}

/* Padding fluido */
.section {
  padding: clamp(2rem, 5vw, 5rem);
}
CSS
/* min(A, B) — elige el valor más pequeño */
.container {
  width: min(90%, 1200px);  /* = max-width: 1200px de forma elegante */
}

.imagen {
  width: min(400px, 100%);   /* nunca mayor a 400px ni al contenedor */
}

/* max(A, B) — elige el valor más grande */
.boton {
  padding: max(0.5rem, 2vw); /* padding mínimo de 0.5rem */
}

.texto {
  font-size: max(1rem, 2vw); /* nunca menor a 1rem */
}

/* Combinando con calc() */
.layout {
  padding: max(1rem, calc(50% - 600px));
}

/* ── env() — variables de entorno del OS/browser ── */
.safe-area {

[data-tooltip]::after {

Animaciones y Transiciones
CSS permite animar propiedades con transition (de A → B al cambiar de estado) y con @keyframes (secuencias completas de animación).
Interactúa — hover sobre las tarjetas
lift
morph
spring
CSS
.boton {
  background: #3498db;
  transform: translateY(0);

  /* transition: propiedad duración timing-function delay */
  transition: all 0.3s ease;

  /* Múltiples propiedades con distintos tiempos */
  transition:
    background 0.2s ease,
    transform  0.3s cubic-bezier(0.34, 1.56, 0.64, 1),
    box-shadow 0.3s ease;
}

.boton:hover {
  background: #2980b9;
  transform: translateY(-4px);
  box-shadow: 0 8px 20px rgba(52, 152, 219, 0.4);
}

/* Funciones de timing */
/* ease | linear | ease-in | ease-out | ease-in-out */
/* steps(n) — animación por pasos (sprite animation) */
/* cubic-bezier(x1,y1,x2,y2) — curva personalizada */
CSS
/* 1. Definir la animación con @keyframes */
@keyframes pulso {
  0%   { transform: scale(1);    opacity: 1; }
  50%  { transform: scale(1.15); opacity: 0.7; }
  100% { transform: scale(1);    opacity: 1; }
}

@keyframes entrar-derecha {
  from { transform: translateX(-30px); opacity: 0; }
  to   { transform: translateX(0);     opacity: 1; }
}

@keyframes girar {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

/* 2. Aplicar con animation */
.elemento-animado {
  /* animation: nombre duración timing delay iter dir fill-mode */
  animation: pulso 2s ease-in-out infinite;
}

.cargando {
  animation: girar 1s linear infinite;
}

.aparece {
  animation: entrar-derecha 0.5s ease-out both;
  /* both = mantiene el estado final */
}

/* Múltiples animaciones */
.combo {
  animation:
    entrar-derecha 0.5s ease-out both,
    pulso 2s 0.5s ease-in-out infinite;
}
