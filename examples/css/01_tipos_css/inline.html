CSS Inline

¿Qué es CSS Inline?

CSS inline se aplica directamente en el elemento HTML usando el atributo style.

Ventajas

  • Alta especificidad (sobrescribe otros estilos)
  • Útil para estilos únicos y específicos
  • No requiere archivos externos

Desventajas

  • Difícil de mantener en proyectos grandes
  • No se puede reutilizar
  • Mezcla contenido con presentación
  • Aumenta el tamaño del HTML
Nota: Use CSS inline solo para estilos muy específicos o en casos donde no tiene acceso a archivos CSS externos.
