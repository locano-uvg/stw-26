CSS Interno

Estilos definidos dentro de la etiqueta <style> en el <head>

¿Qué es CSS Interno?

CSS interno se define dentro de la etiqueta <style> en la sección <head> del documento HTML. Permite aplicar estilos a todo el documento sin necesidad de archivos externos.

<head> <style> .elemento { color: blue; font-size: 16px; } </style> </head>

Ventajas

  • Todo el CSS está en un solo lugar dentro del HTML
  • No requiere archivos externos adicionales
  • Útil para páginas únicas o prototipos rápidos
  • Los estilos se cargan con el HTML

Desventajas

  • No se puede reutilizar en múltiples páginas
  • Aumenta el tamaño del archivo HTML
  • Dificulta el mantenimiento en proyectos grandes
  • No se puede cachear separadamente del HTML
Mejor práctica: Use CSS interno para páginas individuales o cuando necesite estilos específicos que no se reutilizarán. Para proyectos más grandes, prefiera CSS externo.
