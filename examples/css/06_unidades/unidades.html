Unidades CSS

Absolutas, Relativas y Viewport Units

¿Qué son las Unidades CSS?

Las unidades en CSS definen el tamaño y las dimensiones de los elementos. Existen dos categorías principales: unidades absolutas (tamaño fijo) y unidades relativas (se adaptan al contexto).

Importante: Elegir la unidad correcta es fundamental para crear diseños responsive y accesibles.
Tipo Unidad Descripción Uso común
Absolutas px Píxeles Bordes, sombras, elementos fijos
cm Centímetros Impresión
mm Milímetros Impresión
in Pulgadas (1in = 96px) Impresión
pt Puntos (1pt = 1/72in) Impresión, tipografía
pc Picas (1pc = 12pt) Impresión
Relativas % Porcentaje del padre Layouts, width responsive
em Relativo al font-size del elemento Padding, margin, font-size anidado
rem Relativo al font-size del root (:root) Font-size, spacing, diseño moderno
vw 1% del ancho del viewport Anchos responsive, tipografía fluida
vh 1% de la altura del viewport Secciones de pantalla completa
vmin 1% de la dimensión más pequeña del viewport Elementos cuadrados responsive
vmax 1% de la dimensión más grande del viewport Fondos, overlays

Unidades Absolutas

Píxeles (px)

Los píxeles son la unidad absoluta más común en diseño web. Un píxel CSS no siempre equivale a un píxel físico (especialmente en pantallas retina).

width: 200px
.elemento { width: 200px; /* Siempre 200 píxeles */ font-size: 16px; border: 1px solid black; padding: 10px; }
Ventajas de px: Precisión exacta, consistencia, fácil de entender. Ideal para bordes, sombras y elementos que no deben escalar.
Desventajas de px: No escala con la configuración de accesibilidad del navegador, puede causar problemas en diseños responsive.

Unidades Relativas

Porcentaje (%)

El porcentaje es relativo al elemento padre. Muy útil para layouts responsive.

width: 50%
.contenedor { width: 600px; } .elemento { width: 50%; /* 50% de 600px = 300px */ padding: 5%; /* 5% del ancho del padre */ }

em - Relativo al font-size del elemento

em es relativo al font-size del elemento actual. Se compone (multiplica) en elementos anidados.

Contenedor (font-size: 20px)
Hijo (font-size: 1.5em = 30px)
Nieto (font-size: 1.5em = 45px)
1.5 × 30px = 45px (se compone!)
.contenedor { font-size: 20px; } .hijo { font-size: 1.5em; /* 1.5 × 20px = 30px */ } .nieto { font-size: 1.5em; /* 1.5 × 30px = 45px (se multiplica!) */ }

rem - Relativo al font-size del root

rem (root em) siempre es relativo al font-size del elemento :root (generalmente <html>). No se compone en elementos anidados.

Contenedor (font-size: 20px)
Hijo (font-size: 1.5rem = 24px)
Nieto (font-size: 1.5rem = 24px)
Siempre relativo al root (16px × 1.5)
:root { font-size: 16px; /* Base del documento */ } .hijo { font-size: 1.5rem; /* 1.5 × 16px = 24px */ } .nieto { font-size: 1.5rem; /* También 1.5 × 16px = 24px */ }
Mejor práctica moderna: Usa rem para tamaños de fuente y spacing. Es más predecible que em y respeta la configuración de accesibilidad del usuario.

Viewport Units

Las unidades de viewport son relativas al tamaño de la ventana del navegador. Perfectas para diseños responsive y layouts de pantalla completa.

vw - Viewport Width

1vw = 1% del ancho del viewport

10vw
25vw
50vw
75vw

Redimensiona la ventana del navegador para ver cómo cambian los anchos

.hero-section { width: 100vw; /* Ancho completo de la ventana */ height: 100vh; /* Alto completo de la ventana */ } .half-screen { width: 50vw; /* Mitad del ancho */ } /* Tipografía fluida con vw */ h1 { font-size: 5vw; /* Se escala con el viewport */ }

vh - Viewport Height

height: 20vh

vmin y vmax

/* vmin: usa el valor más pequeño entre vw y vh */ .square { width: 50vmin; height: 50vmin; /* Siempre cuadrado */ } /* vmax: usa el valor más grande entre vw y vh */ .full-coverage { width: 100vmax; height: 100vmax; /* Cubre todo el viewport */ }
Cuidado con vw: En móviles, 100vw puede causar scroll horizontal si hay scrollbar vertical. Usa con precaución o combina con max-width: 100%.

Comparación: ¿Cuándo usar cada unidad?

px - Píxeles

Usar para:

  • Bordes (1px, 2px)
  • Sombras
  • Elementos de UI pequeños
  • Cuando necesitas precisión exacta

Evitar para: Font-size principal

% - Porcentaje

Usar para:

  • Layouts de columnas
  • Anchos responsive
  • Sistemas de grid
  • Elementos relativos al padre

Ejemplo: width: 50%

rem - Root EM

Usar para:

  • Font-size (recomendado)
  • Padding y margin
  • Spacing consistente
  • Accesibilidad

Ventaja: Predecible, no se compone

em - Relativo

Usar para:

  • Padding/margin en botones
  • Media queries
  • Componentes que escalan juntos

Cuidado: Se compone en anidados

vw/vh - Viewport

Usar para:

  • Hero sections (100vh)
  • Tipografía fluida
  • Layouts de pantalla completa
  • Elementos que se adaptan al viewport

Combinar: Con clamp() para límites

cm/mm/in - Físicas

Usar para:

  • Hojas de estilo de impresión
  • Documentos físicos
  • PDFs

Evitar: Diseño web regular

Mejores Prácticas 2026

  • ✓ Usa rem para font-size y spacing (accesible y predecible)
  • ✓ Usa % para anchos de columnas y layouts responsivos
  • ✓ Usa px para bordes, sombras y detalles finos
  • ✓ Usa vw/vh para secciones de pantalla completa
  • ✓ Combina clamp() con viewport units para tipografía fluida
  • ✓ Establece font-size: 16px en :root como base
  • ✓ Evita em para font-size (puede componerse inesperadamente)

Ejemplo Práctico: Sistema de Spacing

/* Sistema moderno con rem */ :root { --spacing-xs: 0.25rem; /* 4px */ --spacing-sm: 0.5rem; /* 8px */ --spacing-md: 1rem; /* 16px */ --spacing-lg: 1.5rem; /* 24px */ --spacing-xl: 2rem; /* 32px */ } .card { padding: var(--spacing-lg); margin-bottom: var(--spacing-md); } /* Tipografía fluida con clamp() y viewport units */ h1 { font-size: clamp(2rem, 5vw, 4rem); /* Mínimo 2rem, ideal 5vw, máximo 4rem */ } /* Layout responsive con % */ .column { width: 50%; } @media (max-width: 768px) { .column { width: 100%; } }
