Formatos de Color en CSS

CSS ofrece múltiples formas de especificar colores. Cada formato tiene sus ventajas y casos de uso específicos.

Formato Sintaxis Ejemplo Transparencia
Nombres nombre-color red, blue, tomato No
Hexadecimal #RRGGBB o #RGB #3498db, #fff No (#RRGGBBAA sí)
RGB rgb(R, G, B) rgb(52, 152, 219) No
RGBA rgba(R, G, B, A) rgba(52, 152, 219, 0.5) Sí (0-1)
HSL hsl(H, S%, L%) hsl(204, 70%, 53%) No
HSLA hsla(H, S%, L%, A) hsla(204, 70%, 53%, 0.5) Sí (0-1)

1. Colores con Nombres

CSS incluye 147 nombres de colores predefinidos. Son fáciles de recordar pero limitados.

red
blue
green
orange
purple
tomato
coral
teal
/* Colores con nombres */ .elemento { color: red; background-color: lightblue; border-color: navy; }
Limitación: Los nombres de colores son convenientes pero no permiten ajustes finos y no soportan transparencia.

2. Colores Hexadecimales

El formato hexadecimal es el más común en diseño web. Usa valores del 00 al FF para rojo, verde y azul.

#3498db
#3498db - Azul principal
#2ecc71
#2ecc71 - Verde éxito
#e74c3c
#e74c3c - Rojo peligro
#f39c12
#f39c12 - Naranja advertencia
/* Formato completo: #RRGGBB */ .elemento { color: #3498db; /* Azul */ background-color: #ffffff; /* Blanco */ } /* Formato corto: #RGB (cuando los pares son iguales) */ .otro { color: #fff; /* Equivale a #ffffff */ background-color: #000; /* Equivale a #000000 */ } /* Con transparencia: #RRGGBBAA */ .transparente { background-color: #3498db80; /* Azul con 50% opacidad */ }
Ventaja: Formato compacto y universal, soportado por todas las herramientas de diseño.

3. RGB y RGBA

RGB especifica colores usando valores de 0-255 para Rojo, Verde y Azul. RGBA añade un canal de transparencia (alpha) de 0 a 1.

RGB
rgb(52, 152, 219)
RGBA 0.8
rgba(52, 152, 219, 0.8)
RGBA 0.5
rgba(52, 152, 219, 0.5)
RGBA 0.2
rgba(52, 152, 219, 0.2)
/* RGB básico */ .elemento { color: rgb(52, 152, 219); /* Azul */ background-color: rgb(255, 255, 255); /* Blanco */ } /* RGBA con transparencia */ .overlay { background-color: rgba(0, 0, 0, 0.7); /* Negro 70% opaco */ } .transparente { background-color: rgba(52, 152, 219, 0.3); /* Azul 30% opaco */ }

4. HSL y HSLA

HSL define colores usando Matiz (Hue: 0-360°), Saturación (0-100%) y Luminosidad (0-100%). Es más intuitivo para crear variaciones de color.

Base
hsl(204, 70%, 53%)
Luminosidad: 53%
Más claro
hsl(204, 70%, 70%)
Luminosidad: 70%
Más oscuro
hsl(204, 70%, 35%)
Luminosidad: 35%
Menos saturado
hsl(204, 30%, 53%)
Saturación: 30%
/* HSL - Hue (matiz), Saturation (saturación), Lightness (luminosidad) */ .elemento { color: hsl(204, 70%, 53%); /* Azul base */ background-color: hsl(204, 70%, 90%); /* Azul muy claro */ } /* HSLA con transparencia */ .overlay { background-color: hsla(204, 70%, 53%, 0.5); /* Azul semi-transparente */ } /* Ventaja: Fácil crear variaciones */ .color-base { color: hsl(120, 60%, 50%); } /* Verde */ .color-claro { color: hsl(120, 60%, 70%); } /* Verde claro */ .color-oscuro { color: hsl(120, 60%, 30%); } /* Verde oscuro */
Ventaja de HSL: Facilita crear esquemas de color armónicos y variaciones consistentes ajustando solo la saturación o luminosidad.

5. Gradientes Lineales

Los gradientes crean transiciones suaves entre múltiples colores.

linear-gradient(to right, #3498db, #2ecc71)
linear-gradient(135deg, #667eea, #764ba2)
linear-gradient(to bottom, #f093fb, #f5576c)
linear-gradient(90deg, #ff6b6b 0%, #feca57 50%, #48dbfb 100%)
/* Gradiente básico (de arriba a abajo) */ .elemento { background: linear-gradient(#3498db, #2ecc71); } /* Con dirección */ .horizontal { background: linear-gradient(to right, #3498db, #2ecc71); } /* Con ángulo */ .diagonal { background: linear-gradient(135deg, #667eea, #764ba2); } /* Múltiples colores con posiciones */ .multicolor { background: linear-gradient( 90deg, #ff6b6b 0%, #feca57 50%, #48dbfb 100% ); }

6. Gradientes Radiales

Los gradientes radiales crean transiciones circulares o elípticas desde un punto central.

radial-gradient(circle, #3498db, #2c3e50)
radial-gradient(ellipse at top left, #f093fb, #f5576c)
/* Gradiente radial circular */ .elemento { background: radial-gradient(circle, #3498db, #2c3e50); } /* Elipse con posición */ .elemento { background: radial-gradient(ellipse at top left, #f093fb, #f5576c); } /* Con tamaño específico */ .elemento { background: radial-gradient(circle at center, #fff 0%, #3498db 50%, #2c3e50 100%); }

Palabra Clave: currentColor

currentColor toma el valor del color de texto actual del elemento. Útil para crear componentes consistentes.

/* currentColor usa el color heredado */ .icono { color: #3498db; border: 2px solid currentColor; /* Borde del mismo color */ } .boton { color: #e74c3c; border: 2px solid currentColor; background-color: transparent; } .boton:hover { background-color: currentColor; /* Fondo del color del texto */ color: white; }

Mejores Prácticas

  • ✓ Usa variables CSS para colores reutilizables
  • ✓ Mantén una paleta consistente (5-7 colores principales)
  • ✓ Verifica contraste para accesibilidad (mínimo 4.5:1 para texto)
  • ✓ Usa HSL para crear variaciones de color fácilmente
  • ✓ RGBA/HSLA para transparencias en overlays y sombras
  • ✓ Hexadecimal para colores sólidos (más compacto)
  • ✓ Prueba colores en diferentes pantallas y modos (claro/oscuro)
