Tipografía en CSS

Fuentes, tamaños, estilos y mejores prácticas

Propiedades Tipográficas Fundamentales

La tipografía es uno de los aspectos más importantes del diseño web. CSS ofrece numerosas propiedades para controlar la apariencia del texto.

Propiedad Descripción Valores Comunes
font-family Define la familia de fuentes serif, sans-serif, monospace
font-size Tamaño de la fuente px, rem, em, %, vw
font-weight Grosor de la fuente normal, bold, 100-900
font-style Estilo de la fuente normal, italic, oblique
line-height Altura de línea (interlineado) número, px, rem, %
letter-spacing Espaciado entre caracteres px, em, rem
text-align Alineación del texto left, center, right, justify
text-transform Transformación del texto uppercase, lowercase, capitalize
text-decoration Decoración del texto underline, line-through, none

1. Font-Family: Familias de Fuentes

Define qué tipo de letra se usará. Se pueden especificar múltiples fuentes como fallback (font stack).

Fuentes Web-Safe

Serif (Georgia, Times New Roman)
Las fuentes serif tienen pequeños trazos decorativos. Tradicionales y formales. Ideales para textos largos en medios impresos.
Sans-serif (Arial, Helvetica)
Las fuentes sans-serif son limpias y modernas, sin trazos decorativos. Más legibles en pantallas digitales.
Monospace (Courier New, Monaco)
Todos los caracteres tienen el mismo ancho. Perfectas para código y datos tabulares. Proporcionan alineación uniforme.
/* Font stacks (lista de fuentes con fallback) */ body { font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; } h1 { font-family: Georgia, 'Times New Roman', serif; } code { font-family: 'Courier New', Courier, monospace; }

Google Fonts (Web Fonts)

Poppins (Google Font)
Fuente moderna y geométrica. Excelente legibilidad y aspecto contemporáneo. Popular para interfaces de usuario modernas.
Roboto Mono (Google Font)
Fuente monoespaciada moderna. Ideal para código y contenido técnico. Diseñada específicamente para pantallas.
/* 1. Incluir en el <head> del HTML */ <link href="https://fonts.googleapis.com/css2?family=Poppins:wght@300;400;600;700&display=swap" rel="stylesheet"> /* 2. Usar en CSS */ body { font-family: 'Poppins', sans-serif; }
Consejo: Visita fonts.google.com para explorar miles de fuentes gratuitas y sus combinaciones recomendadas.

2. Font-Size: Tamaño de Fuente

Controla el tamaño del texto. Es crucial para la jerarquía visual y legibilidad.

Extra pequeño (0.75rem / 12px)

Pequeño (0.875rem / 14px)

Base (1rem / 16px)

Grande (1.125rem / 18px)

Extra grande (1.25rem / 20px)

2XL (1.5rem / 24px)

3XL (1.875rem / 30px)

4XL (2.25rem / 36px)

/* Píxeles - Fijo, no escala */ .texto { font-size: 16px; } /* REM - Relativo al root (recomendado) */ .texto { font-size: 1rem; } /* 1rem = 16px por defecto */ .grande { font-size: 1.5rem; } /* 24px */ /* EM - Relativo al padre */ .texto { font-size: 1.2em; } /* Viewport width - Responsive */ .titulo { font-size: 5vw; } /* clamp() - Tipografía fluida (moderno) */ .responsive { font-size: clamp(1rem, 2.5vw, 2rem); /* mínimo 1rem, ideal 2.5vw, máximo 2rem */ }

Tipografía Responsive con clamp()

Este texto se escala automáticamente entre 1rem y 2rem
Mejor Práctica: Usa REM para tamaños de fuente y clamp() para tipografía responsive fluida sin media queries.

3. Font-Weight: Grosor de la Fuente

Controla el grosor de los caracteres. Valores numéricos de 100 a 900.

Light (300) - Texto ligero y delicado

Normal (400) - Peso estándar del texto

Semi-bold (600) - Énfasis moderado

Bold (700) - Texto en negrita

/* Valores nombrados */ .texto { font-weight: normal; } /* 400 */ .negrita { font-weight: bold; } /* 700 */ /* Valores numéricos (100-900) */ .ligero { font-weight: 300; } .normal { font-weight: 400; } .semibold { font-weight: 600; } .negrita { font-weight: 700; } .extra-negrita { font-weight: 900; }
Nota: No todas las fuentes soportan todos los pesos. Verifica qué pesos están disponibles antes de usarlos.

4. Text-Align: Alineación del Texto

Left (Izquierda)

Alineación por defecto en idiomas occidentales. Texto alineado al margen izquierdo.

Center (Centrado)

Texto centrado horizontalmente. Ideal para títulos y elementos destacados.

Right (Derecha)

Texto alineado al margen derecho. Menos común, usado para efectos especiales.

Justify (Justificado)

El texto se distribuye uniformemente entre ambos márgenes, creando líneas del mismo ancho. Común en publicaciones impresas pero puede dificultar la lectura en pantallas.

.izquierda { text-align: left; } .centrado { text-align: center; } .derecha { text-align: right; } .justificado { text-align: justify; }

5. Text-Transform: Transformación de Texto

uppercase - todo en mayúsculas

LOWERCASE - TODO EN MINÚSCULAS

capitalize - primera letra en mayúscula

none - Sin transformación

.mayusculas { text-transform: uppercase; } .minusculas { text-transform: lowercase; } .capitalizar { text-transform: capitalize; } .normal { text-transform: none; }

6. Text-Decoration: Decoración del Texto

Texto subrayado (underline)

Texto tachado (line-through)

Sin decoración (none) - útil para enlaces

Subrayado ondulado rojo (CSS3)

.subrayado { text-decoration: underline; } .tachado { text-decoration: line-through; } .sin-decoracion { text-decoration: none; } /* CSS3 - Decoración avanzada */ .fancy { text-decoration: underline wavy red; }

7. Line-Height: Interlineado

Controla el espacio vertical entre líneas de texto. Crucial para legibilidad.

Tight (1.25)

El interlineado ajustado reduce el espacio entre líneas. Útil para títulos pero puede dificultar la lectura en párrafos largos. Proporciona una apariencia compacta.

Normal (1.5)

El interlineado normal (1.5) es el estándar recomendado para la mayoría del texto. Proporciona buena legibilidad sin desperdiciar espacio vertical. Equilibrio perfecto para contenido web.

Relaxed (1.75)

El interlineado relajado aumenta el espacio entre líneas. Mejora la legibilidad en textos largos y facilita la lectura. Ideal para artículos y documentos extensos.

Loose (2)

El interlineado amplio proporciona máximo espacio entre líneas. Puede ser útil para diseños específicos o accesibilidad. Aumenta significativamente la altura del contenido.

/* Sin unidad (recomendado) - Multiplica el tamaño de fuente */ p { line-height: 1.6; } /* Con unidad */ p { line-height: 24px; } p { line-height: 1.5rem; }
Recomendación: Para texto de párrafo, usa line-height entre 1.5 y 1.75 para óptima legibilidad.

8. Letter-Spacing: Espaciado entre Caracteres

Tracking tight: Espaciado reducido (-0.05em)

Tracking normal: Espaciado estándar (0)

Tracking wide: Espaciado amplio (0.05em)

Tracking wider: Espaciado muy amplio (0.1em)

.ajustado { letter-spacing: -0.05em; } .normal { letter-spacing: 0; } .amplio { letter-spacing: 0.05em; } .muy-amplio { letter-spacing: 0.1em; } /* Útil para títulos en mayúsculas */ .titulo-mayusculas { text-transform: uppercase; letter-spacing: 0.1em; }

9. Text-Shadow: Sombra de Texto

Sombra pequeña

Sombra media

Sombra grande

Efecto de resplandor

/* Sintaxis: x-offset y-offset blur color */ h1 { text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.3); } /* Múltiples sombras */ .fancy { text-shadow: 1px 1px 2px rgba(0,0,0,0.3), 0 0 10px rgba(52, 152, 219, 0.5); } /* Efecto de texto grabado */ .engraved { color: #666; text-shadow: 1px 1px 0 rgba(255,255,255,0.5); }

Jerarquía Tipográfica

Una buena jerarquía tipográfica guía al lector a través del contenido.

Título Principal (H1) - 2.5rem

El título principal debe ser el elemento más grande y prominente de la página.

Título Secundario (H2) - 2rem

Los títulos secundarios dividen el contenido en secciones principales.

Título Terciario (H3) - 1.5rem

Los títulos terciarios subdividen las secciones en temas más específicos.

Título Cuaternario (H4) - 1.25rem

Los títulos cuaternarios proporcionan un nivel adicional de organización.

Texto en negrita para énfasis fuerte.

Texto en cursiva para énfasis suave o citas.

Texto de párrafo normal con buen interlineado y tamaño legible.

Texto pequeño para notas al pie o información secundaria.

/* Sistema de jerarquía tipográfica */ h1 { font-size: 2.5rem; font-weight: 700; line-height: 1.2; } h2 { font-size: 2rem; font-weight: 600; line-height: 1.3; } h3 { font-size: 1.5rem; font-weight: 600; line-height: 1.4; } h4 { font-size: 1.25rem; font-weight: 600; line-height: 1.4; } p { font-size: 1rem; line-height: 1.6; margin-bottom: 1rem; } small { font-size: 0.875rem; color: #666; }

Mejores Prácticas de Tipografía

  • ✓ Usa máximo 2-3 familias de fuentes en un proyecto
  • ✓ Mantén line-height entre 1.5-1.75 para texto de párrafo
  • ✓ Usa REM para tamaños de fuente (mejor accesibilidad)
  • ✓ Limita la longitud de línea a 50-75 caracteres para lectura óptima
  • ✓ Asegura suficiente contraste entre texto y fondo
  • ✓ Usa font-weight para crear jerarquía visual
  • ✓ Considera la legibilidad en dispositivos móviles
  • ✓ Usa clamp() para tipografía responsive fluida
  • ✓ Optimiza la carga de web fonts (solo los pesos necesarios)
