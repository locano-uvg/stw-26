Display Property

Controlando el tipo de visualización de elementos

¿Qué es la propiedad Display?

La propiedad display es una de las más importantes en CSS. Determina cómo se comporta y renderiza un elemento en el flujo del documento. Controla si un elemento es de bloque, en línea, un contenedor flex, grid, o si se oculta completamente.

Importante: La propiedad display afecta tanto al elemento en sí como a sus elementos hijos, especialmente con valores como flex y grid.
Valor Descripción Comportamiento
block Elemento de bloque Ocupa todo el ancho disponible, inicia en nueva línea
inline Elemento en línea Solo ocupa el ancho de su contenido, no acepta width/height
inline-block Híbrido inline-block En línea pero acepta width/height
none Oculto completamente No se renderiza ni ocupa espacio
flex Contenedor flexible Crea un contexto de flexbox para sus hijos
grid Contenedor de cuadrícula Crea un contexto de grid para sus hijos
inline-flex Flex en línea Flexbox pero comportamiento inline
inline-grid Grid en línea Grid pero comportamiento inline

display: block

Los elementos con display: block ocupan todo el ancho disponible y comienzan en una nueva línea. Ejemplos: <div>, <p>, <h1>, <section>.

Bloque 1 - Ocupa todo el ancho
Bloque 2 - Nueva línea automáticamente
Bloque 3 - Acepta width, height, margin, padding
.elemento { display: block; width: 100%; /* Puede especificar width */ height: 50px; /* Puede especificar height */ margin: 10px 0; /* Acepta todos los márgenes */ }
Características de block: Comienza en nueva línea, ocupa todo el ancho disponible, acepta width y height, respeta márgenes verticales y horizontales.

display: inline

Los elementos con display: inline solo ocupan el espacio necesario para su contenido y no fuerzan un salto de línea. Ejemplos: <span>, <a>, <strong>, <em>.

Este es un párrafo con elemento inline 1 y otro elemento inline 2 en la misma línea. No saltan a nueva línea y solo ocupan el espacio de su contenido.
.elemento { display: inline; /* NO acepta width y height */ /* Solo margin y padding horizontales (left/right) */ margin: 0 10px; /* Solo horizontal funciona bien */ padding: 0 5px; /* Solo horizontal funciona bien */ }
Limitación de inline: No acepta width ni height, y los márgenes/padding verticales no afectan el flujo del documento.

display: inline-block

display: inline-block combina lo mejor de ambos mundos: se comporta como inline (no salta de línea) pero acepta width, height, y todos los márgenes como block.

.elemento { display: inline-block; width: 150px; /* SÍ acepta width */ height: 80px; /* SÍ acepta height */ margin: 10px; /* Todos los márgenes funcionan */ padding: 15px; /* Todo el padding funciona */ }
Uso común: Botones, badges, cards en línea, menús de navegación horizontal.

display: none

display: none oculta completamente el elemento. No se renderiza y no ocupa espacio en el documento. Es diferente a visibility: hidden que oculta pero mantiene el espacio.

Este elemento puede ocultarse con display: none
.oculto { display: none; /* Completamente removido del flujo */ } .visible { display: block; /* Visible y en el flujo */ } /* Comparación */ .hidden-visibility { visibility: hidden; /* Oculto pero ocupa espacio */ }

display: flex

display: flex convierte el elemento en un contenedor flexible, permitiendo un control avanzado sobre la disposición de sus elementos hijos.

.contenedor { display: flex; gap: 10px; /* Espacio entre items */ justify-content: space-between; /* Distribución horizontal */ align-items: center; /* Alineación vertical */ } .item { flex: 1; /* Crecen equitativamente */ }
Flexbox: Ideal para layouts unidimensionales (fila o columna), navegación, centrado de elementos, distribución de espacio.

display: grid

display: grid crea un contenedor de cuadrícula bidimensional, perfecto para layouts complejos con filas y columnas.

Grid: Ideal para layouts bidimensionales, sistemas de cuadrícula complejos, layouts de página completa.

Comparación de Valores Display

block

✓ Ocupa todo el ancho

✓ Nueva línea

✓ Acepta width/height

✓ Todos los márgenes

Uso: Secciones, contenedores

inline

✓ Solo ancho del contenido

✓ Misma línea

✗ No acepta width/height

✗ Solo margin horizontal

Uso: Texto, enlaces, spans

inline-block

✓ Ancho personalizable

✓ Misma línea

✓ Acepta width/height

✓ Todos los márgenes

Uso: Botones, badges, cards inline

flex

✓ Layout unidimensional

✓ Control de dirección

✓ Alineación avanzada

✓ Distribución de espacio

Uso: Navbars, layouts flexibles

grid

✓ Layout bidimensional

✓ Filas y columnas

✓ Grid areas nombradas

✓ Control preciso

Uso: Layouts complejos, páginas

none

✓ Oculta elemento

✓ No ocupa espacio

✓ Removido del flujo

✓ Toggle con JS

Uso: Modales, menús, toggles

Mejores Prácticas

  • ✓ Usa flex para layouts de una dimensión (fila o columna)
  • ✓ Usa grid para layouts bidimensionales complejos
  • ✓ Usa inline-block para elementos en línea con dimensiones
  • ✓ Usa none para ocultar elementos con JavaScript
  • ✓ Conoce el valor por defecto de cada elemento HTML
  • ✓ Combina display con otras propiedades para control total del layout
