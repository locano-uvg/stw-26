CSS Variables (Custom Properties)

Conceptos básicos y uso fundamental

¿Qué son las Variables CSS?

Las variables CSS (también llamadas Custom Properties) permiten almacenar valores que pueden reutilizarse en todo el documento. Se definen con el prefijo -- y se acceden usando la función var().

/* 1. Definir variables en :root (disponibles globalmente) */ :root { --primary-color: #3498db; --spacing-md: 16px; --border-radius: 8px; } /* 2. Usar las variables con var() */ .button { background-color: var(--primary-color); padding: var(--spacing-md); border-radius: var(--border-radius); }
Ventaja principal: Al cambiar el valor de una variable en :root, todos los elementos que la usan se actualizan automáticamente.

Sintaxis y Definición

1. Definir Variables

/* En :root para alcance global */ :root { --color-principal: #3498db; --espaciado-base: 16px; } /* En un selector específico para alcance local */ .card { --card-bg: white; --card-padding: 20px; }

2. Usar Variables

/* Sintaxis: var(nombre-variable) */ .elemento { color: var(--color-principal); padding: var(--espaciado-base); } /* Con valor de fallback */ .otro-elemento { color: var(--color-inexistente, blue); /* Si --color-inexistente no existe, usa blue */ }

Ventajas de las Variables CSS

1. Mantenibilidad

Cambia un valor en un solo lugar y se actualiza en todo el sitio.

2. Reutilización

Define una vez, usa en múltiples lugares.

3. Legibilidad

Nombres descriptivos hacen el código más entendible.

4. Dinamismo

Pueden modificarse con JavaScript en tiempo real.

5. Alcance

Pueden ser globales (:root) o locales (cualquier selector).

6. Fallbacks

Soportan valores por defecto con var(--var, fallback).

Mejor Práctica

Organice sus variables CSS en categorías (colores, espaciado, tipografía, etc.) y defínalas en :root para facilitar el mantenimiento y la creación de temas.

Modificar Variables con JavaScript

// Leer una variable const color = getComputedStyle(document.documentElement) .getPropertyValue('--primary-color'); // Modificar una variable document.documentElement.style .setProperty('--primary-color', '#e74c3c'); // Cambiar variable en un elemento específico document.querySelector('.card').style .setProperty('--card-bg', 'lightblue');
Nota: Esta capacidad de modificar variables con JavaScript las hace ideales para crear temas dinámicos y componentes interactivos.
