Combinadores CSS

Selectores que relacionan elementos entre sí

Referencia Rápida de Combinadores

Combinador Símbolo Descripción Ejemplo
Descendente (espacio) Selecciona todos los descendientes div p
Hijo directo > Selecciona solo hijos directos div > p
Hermano adyacente + Selecciona el elemento inmediatamente siguiente h3 + p
Hermanos generales ~ Selecciona todos los hermanos siguientes h3 ~ p

1. Combinador Descendente (espacio)

Selecciona TODOS los elementos descendientes, sin importar el nivel de anidación.

/* CSS - Selecciona todos los <p> dentro de .demo-descendente */ .demo-descendente p { color: #2c3e50; background-color: #e3f2fd; }

Demostración:

Párrafo hijo directo (afectado)

Párrafo nieto (también afectado)

Párrafo bisnieto (también afectado)

.demo-descendente
<p> ← Seleccionado
<div>
<p> ← Seleccionado
<div>
<p> ← Seleccionado

2. Combinador Hijo Directo (>)

Selecciona SOLO los elementos hijos DIRECTOS, no los nietos ni descendientes más profundos.

/* CSS - Solo hijos directos */ .demo-hijo > p { background-color: #fff3cd; font-weight: bold; }

Demostración:

Párrafo hijo directo (afectado con fondo amarillo)

Otro párrafo hijo directo (afectado con fondo amarillo)

Párrafo nieto (NO afectado, fondo normal)

.demo-hijo
<p> ← Seleccionado (hijo directo)
<p> ← Seleccionado (hijo directo)
<div>
<p> ← NO seleccionado (nieto)

3. Combinador Hermano Adyacente (+)

Selecciona SOLO el elemento que viene INMEDIATAMENTE después del selector.

/* CSS - Solo el primer <p> después de <h3> */ h3 + p { background-color: #d4edda; font-weight: bold; }

Demostración:

Título

Este párrafo viene INMEDIATAMENTE después del h3 (afectado con fondo verde)

Este párrafo NO viene inmediatamente después del h3 (NO afectado)

Tercer párrafo (NO afectado)

Uso común: Eliminar el margin-top del primer párrafo después de un título.
h2 + p { margin-top: 0; /* Elimina espacio superior */ }

4. Combinador Hermanos Generales (~)

Selecciona TODOS los elementos hermanos que vienen DESPUÉS del selector.

/* CSS - Todos los <p> que vienen después de <h3> */ h3 ~ p { background-color: #f8d7da; }

Demostración:

Párrafo ANTES del h3 (NO afectado)

Título

Primer párrafo después del h3 (afectado con fondo rojo)

Segundo párrafo después del h3 (afectado con fondo rojo)

Tercer párrafo después del h3 (afectado con fondo rojo)

Contenedor
<p> ← NO seleccionado (antes de h3)
<h3>
<p> ← Seleccionado
<p> ← Seleccionado
<p> ← Seleccionado

5. Comparación: Adyacente (+) vs Hermanos Generales (~)

Combinador Cantidad seleccionada Condición
h3 + p Solo 1 elemento El siguiente inmediato
h3 ~ p Todos los siguientes Todos los hermanos posteriores
Ejemplo práctico: Estilizar formularios
/* Agregar margen a todos los inputs después del primero */ input + input { margin-top: 10px; } /* Cambiar color a todos los labels después de un input:invalid */ input:invalid ~ label { color: red; }

6. Casos de Uso Comunes

Descendente (espacio)

/* Todos los enlaces dentro del nav */ nav a { text-decoration: none; color: white; } /* Todos los items dentro de una lista */ .menu li { display: inline-block; }

Hijo Directo (>)

/* Solo items directos del menu, no subitems */ .menu > li { border-right: 1px solid #ccc; } /* Solo párrafos directos del artículo */ article > p { font-size: 18px; }

Hermano Adyacente (+)

/* Eliminar margen del primer párrafo después del título */ h2 + p { margin-top: 0; } /* Estilo especial para el primer elemento después de un checkbox */ input[type="checkbox"]:checked + label { color: green; font-weight: bold; }

Hermanos Generales (~)

/* Todos los párrafos después de una imagen */ img ~ p { text-indent: 20px; } /* Ocultar elementos después de uno activo */ .tab.active ~ .tab { opacity: 0.5; }
