Pseudo-clases CSS

Selectores que definen estados especiales de elementos

1. Pseudo-clases de Interacción

:hover (Al pasar el cursor)

Pasa el cursor sobre mí
/* CSS */ .elemento:hover { background-color: #2980b9; transform: translateY(-5px); }

:active (Al hacer clic)

Haz clic y mantén presionado
/* CSS */ .elemento:active { transform: scale(0.95); }

:focus (Cuando tiene foco)

/* CSS */ input:focus { border-color: #3498db; box-shadow: 0 0 0 3px rgba(52, 152, 219, 0.2); }

2. Pseudo-clases Estructurales

:first-child y :last-child

  • Primer elemento (con :first-child)
  • Elemento normal
  • Elemento normal
  • Elemento normal
  • Último elemento (con :last-child)
/* CSS */ li:first-child { background-color: #d4edda; font-weight: bold; } li:last-child { background-color: #cce5ff; font-weight: bold; }

:nth-child(odd) y :nth-child(even)

  • Elemento 1 (impar)
  • Elemento 2 (par)
  • Elemento 3 (impar)
  • Elemento 4 (par)
  • Elemento 5 (impar)
  • Elemento 6 (par)
/* CSS */ li:nth-child(odd) { background-color: #f8f9fa; } li:nth-child(even) { background-color: #ffffff; }

:nth-child(3n) - Cada tercer elemento

  • Elemento 1
  • Elemento 2
  • Elemento 3 (destacado)
  • Elemento 4
  • Elemento 5
  • Elemento 6 (destacado)
  • Elemento 7
  • Elemento 8
  • Elemento 9 (destacado)
/* CSS */ li:nth-child(3n) { background-color: #fff3cd; border-left: 4px solid #ffc107; }

:not() - Selector de negación

  • Elemento normal
  • Elemento especial
  • Elemento normal
  • Elemento especial
  • Elemento normal
/* CSS */ li:not(.special) { color: #6c757d; opacity: 0.7; } li.special { background: linear-gradient(135deg, #f093fb 0%, #f5576c 100%); color: white; }

3. Pseudo-clases de Enlaces

Enlace no visitado (:link) Otro enlace (:link y :hover)
/* CSS */ a:link { color: #3498db; } a:visited { color: #9b59b6; } a:hover { background-color: #f8f9fa; transform: translateX(10px); }

4. Pseudo-clases de Formularios

/* CSS */ input:focus { border-color: #667eea; box-shadow: 0 0 0 3px rgba(102, 126, 234, 0.1); } input:disabled { background-color: #e9ecef; cursor: not-allowed; } input:required { border-left: 4px solid #e74c3c; } .checkbox-demo:has(input:checked) { background-color: #d4edda; border-left: 4px solid #28a745; }

5. Referencia Rápida de Pseudo-clases

Pseudo-clase Descripción Ejemplo de uso
:hover Al pasar el cursor Botones, enlaces, cards interactivas
:active Al hacer clic Feedback visual en botones
:focus Cuando tiene foco Inputs, campos de formulario
:first-child Primer hijo Destacar primer elemento de lista
:last-child Último hijo Remover border del último item
:nth-child(n) n-ésimo hijo Filas alternadas, patrones
:not(selector) Negación Aplicar estilos excepto a ciertos elementos
:checked Input marcado Estilos para checkboxes/radios activos
:disabled Elemento deshabilitado Inputs deshabilitados
:required Campo requerido Indicar campos obligatorios
