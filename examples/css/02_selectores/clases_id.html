Clases e ID en CSS

Entendiendo la diferencia y cuándo usar cada uno

¿Qué son los Selectores de ID?

Los ID se definen con el símbolo # y deben ser únicos en la página. Se utilizan para identificar un elemento específico que aparece una sola vez.

/* CSS */ #header { background-color: blue; padding: 20px; } /* HTML */ <header id="header">...</header>
Importante: Un ID solo puede usarse una vez por página. No reutilice IDs.

¿Qué son las Clases?

Las clases se definen con el símbolo . y pueden reutilizarse en múltiples elementos. Son ideales para aplicar estilos consistentes a varios elementos.

/* CSS */ .card { background-color: white; padding: 20px; border-radius: 8px; } /* HTML */ <div class="card">...</div> <div class="card">...</div> <div class="card">...</div>
Ventaja: Las clases son reutilizables y más flexibles para el diseño moderno.

Comparación: Clases vs ID

Característica Clase (.) ID (#)
Símbolo .nombre-clase #nombre-id
Reutilización Múltiples elementos Solo un elemento
Especificidad Baja (0,0,1,0) Alta (0,1,0,0)
Uso principal Estilos y diseño JavaScript, anclas, elementos únicos
Mejor práctica Preferido para CSS Usar con moderación

Múltiples Clases en un Elemento

Un elemento HTML puede tener múltiples clases separadas por espacios. Esto permite combinar estilos de diferentes clases.

/* HTML */ <div class="card highlight-box"> Este elemento tiene dos clases </div> <button class="btn btn-primary btn-large"> Botón con tres clases </button>

Mejor Práctica Profesional

Prefiera clases sobre IDs para CSS. Las clases son más flexibles, reutilizables y tienen menor especificidad, lo que facilita el mantenimiento del código. Reserve los IDs para JavaScript, anclas de navegación y elementos verdaderamente únicos.
