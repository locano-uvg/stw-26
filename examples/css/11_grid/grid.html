CSS Grid Layout

Sistema de layout bidimensional potente y flexible

¿Qué es CSS Grid?

CSS Grid Layout es un sistema de diseño bidimensional que permite crear layouts complejos organizando elementos en filas y columnas simultáneamente. Es ideal para diseños de página completa y componentes complejos.

Grid vs Flexbox: Grid trabaja en dos dimensiones (filas Y columnas), mientras que Flexbox trabaja en una dimensión (fila O columna). Son complementarios, no excluyentes.

Propiedades Principales del Grid Container

Propiedad Descripción Valores
display Define un contenedor grid grid, inline-grid
grid-template-columns Define las columnas px, fr, %, auto, repeat(), minmax()
grid-template-rows Define las filas px, fr, %, auto, repeat(), minmax()
grid-template-areas Define áreas con nombres Nombres personalizados
gap Espacio entre celdas px, rem, %
justify-items Alineación horizontal de items start, end, center, stretch
align-items Alineación vertical de items start, end, center, stretch

Unidad FR: La unidad "fr" (fraction) distribuye el espacio disponible proporcionalmente. Es la forma más flexible de definir tamaños en Grid.

/* Grid responsive sin media queries */ .grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); gap: 16px; } /* auto-fit: Crea tantas columnas como quepan minmax(200px, 1fr): Mínimo 200px, máximo 1fr Resultado: Columnas que se ajustan automáticamente al ancho disponible */
auto-fit vs auto-fill:
• auto-fit: Colapsa las celdas vacías y expande las existentes
• auto-fill: Mantiene las celdas vacías

/* Definir el grid con áreas nombradas */ .layout { display: grid; grid-template-columns: 1fr 2fr 1fr; grid-template-rows: auto 1fr auto; grid-template-areas: "header header header" "sidebar main aside" "footer footer footer"; gap: 16px; min-height: 400px; } /* Asignar elementos a las áreas */ .header { grid-area: header; } .sidebar { grid-area: sidebar; } .main { grid-area: main; } .aside { grid-area: aside; } .footer { grid-area: footer; }
Ventaja: Grid template areas hace el código muy legible. Puedes visualizar el layout directamente en el CSS.

Los items pueden ocupar múltiples columnas o filas usando span.

.grid { display: grid; grid-template-columns: repeat(4, 1fr); gap: 16px; } /* Hacer que un item ocupe múltiples columnas */ .item-wide { grid-column: span 2; /* Ocupa 2 columnas */ } .item-full { grid-column: span 4; /* Ocupa 4 columnas (ancho completo) */ } /* También funciona con filas */ .item-tall { grid-row: span 2; /* Ocupa 2 filas */ } /* Posicionamiento específico */ .item-positioned { grid-column: 2 / 4; /* Desde línea 2 hasta línea 4 */ grid-row: 1 / 3; /* Desde línea 1 hasta línea 3 */ }

Funciones Especiales de Grid

Función Sintaxis Descripción
repeat() repeat(n, tamaño) Repite un patrón n veces
minmax() minmax(min, max) Define tamaño mínimo y máximo
auto-fit repeat(auto-fit, ...) Ajusta columnas al espacio disponible
auto-fill repeat(auto-fill, ...) Llena con columnas, mantiene vacías
fr 1fr, 2fr, etc. Fracción del espacio disponible
/* Combinando funciones para layouts avanzados */ /* Layout con columna fija y flexible */ .layout { grid-template-columns: 250px 1fr; /* Sidebar fijo, contenido flexible */ } /* Columnas que nunca son más pequeñas que 200px */ .grid { grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); } /* Tres columnas, la del medio crece más */ .grid { grid-template-columns: 1fr 2fr 1fr; } /* Filas automáticas con tamaño mínimo */ .grid { grid-template-rows: repeat(3, minmax(100px, auto)); } /* Grid denso (rellena huecos automáticamente) */ .grid { grid-auto-flow: dense; }

Alineación en Grid

/* Alinear todos los items */ .grid { justify-items: center; /* Horizontal: start | end | center | stretch */ align-items: center; /* Vertical: start | end | center | stretch */ } /* Alinear el contenido del grid completo */ .grid { justify-content: center; /* Alineación horizontal del grid */ align-content: center; /* Alineación vertical del grid */ } /* Alinear un item específico */ .item { justify-self: center; /* Horizontal */ align-self: center; /* Vertical */ } /* Shorthand para centrar */ .grid { place-items: center; /* = align-items + justify-items */ }

Mejores Prácticas de CSS Grid

  • ✓ Usa Grid para layouts bidimensionales (página completa)
  • ✓ Aprovecha grid-template-areas para layouts complejos legibles
  • ✓ Combina auto-fit + minmax() para grids responsive sin media queries
  • ✓ Usa unidades FR en lugar de porcentajes para mayor flexibilidad
  • ✓ Gap es mejor que margins para espaciado entre items
  • ✓ Considera Grid para el layout general, Flexbox para componentes
  • ✓ Usa repeat() para evitar repetir código
  • ✓ Aprovecha grid-auto-flow: dense para diseños tipo masonry

Grid vs Flexbox: Guía de Uso

Escenario Recomendación Razón
Layout de página completa Grid Control bidimensional preciso
Barra de navegación Flexbox Layout unidimensional simple
Galería de imágenes Grid Estructura regular en 2D
Lista de cards en fila Flexbox Alineación flexible en 1D
Dashboard con widgets Grid Layout complejo bidimensional
Centrar elemento Flexbox Más simple para centrado
Formulario con campos Grid Alineación precisa de labels e inputs
Recuerda: Grid y Flexbox no son competidores, son complementarios. Puedes (y debes) usar ambos en el mismo proyecto donde cada uno tenga sentido.
