Flexbox - CSS

Sistema de layout flexible y poderoso

¿Qué es Flexbox?

Flexbox (Flexible Box Layout) es un modelo de layout CSS que permite diseñar layouts complejos de forma más eficiente. Proporciona una manera más eficaz de distribuir espacio y alinear contenido entre elementos, incluso cuando su tamaño es dinámico o desconocido.

Concepto clave: Flexbox trabaja con un eje principal (main axis) y un eje transversal (cross axis). La dirección del eje principal se define con flex-direction.

Conceptos Fundamentales

Término Descripción
Flex Container El elemento padre con display: flex
Flex Items Los hijos directos del flex container
Main Axis Eje principal (horizontal por defecto)
Cross Axis Eje transversal (perpendicular al main axis)

Propiedades del Flex Container

Propiedad Descripción Valores
display Define un contenedor flex flex, inline-flex
flex-direction Dirección del eje principal row, row-reverse, column, column-reverse
flex-wrap Permite que los items se envuelvan nowrap, wrap, wrap-reverse
justify-content Alineación en el eje principal flex-start, flex-end, center, space-between, space-around, space-evenly
align-items Alineación en el eje transversal flex-start, flex-end, center, stretch, baseline
align-content Alineación de líneas múltiples flex-start, flex-end, center, space-between, space-around, stretch

Propiedades de los Flex Items

Propiedad Descripción Valores
flex-grow Capacidad de crecer número (0 = no crece)
flex-shrink Capacidad de encogerse número (0 = no se encoge)
flex-basis Tamaño base antes de distribución px, rem, %, auto
flex Shorthand para grow, shrink, basis flex: grow shrink basis
align-self Alineación individual del item auto, flex-start, flex-end, center, stretch
order Orden de visualización número (por defecto 0)

Flex-Grow: Distribución del Espacio Extra

flex-grow: 1
flex-grow: 2
flex-grow: 1
/* Items crecen proporcionalmente */ .item-1 { flex-grow: 1; } /* Toma 1 parte del espacio disponible */ .item-2 { flex-grow: 2; } /* Toma 2 partes (el doble) */ .item-3 { flex-grow: 1; } /* Toma 1 parte */

Flex Shorthand

/* flex: grow shrink basis */ .item { flex: 1 1 auto; /* Crece y se encoge, tamaño auto */ } /* Valores comunes */ .item { flex: 1; } /* = flex: 1 1 0 (flexible) */ .item { flex: auto; } /* = flex: 1 1 auto */ .item { flex: none; } /* = flex: 0 0 auto (inflexible) */

Mejores Prácticas de Flexbox

  • ✓ Usa flexbox para layouts en una dimensión (fila o columna)
  • ✓ Prefiere gap sobre margins para espaciado entre items
  • ✓ Usa flex shorthand en lugar de propiedades individuales
  • ✓ Combina justify-content y align-items para centrado perfecto
  • ✓ flex-wrap: wrap para layouts responsive automáticos
  • ✓ Usa flex: 1 para distribuir espacio equitativamente
  • ✓ Considera Grid para layouts bidimensionales complejos
  • ✓ Prueba en diferentes tamaños de pantalla

Flexbox vs Grid: ¿Cuándo usar cada uno?

Aspecto Flexbox Grid
Dimensiones Una dimensión (fila O columna) Dos dimensiones (filas Y columnas)
Uso ideal Componentes, navegación, alineación Layouts de página completa
Control Basado en contenido (content-first) Basado en layout (layout-first)
Ejemplos Navbar, cards en fila, centrado Grillas de productos, dashboard
Consejo: No son excluyentes. Puedes usar Grid para el layout general y Flexbox para los componentes individuales.
