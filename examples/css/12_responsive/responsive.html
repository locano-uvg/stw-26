Diseño Responsive CSS

Media queries y técnicas modernas

¿Qué es el Diseño Responsive?

El diseño responsive es una técnica de desarrollo web que permite que un sitio web se adapte automáticamente a diferentes tamaños de pantalla y dispositivos. Se logra principalmente mediante media queries, layouts flexibles y unidades relativas.

Viewport Meta Tag: Esencial para responsive design. Asegúrate de incluirlo en el <head> de tu HTML:
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Breakpoints Comunes

Dispositivo Ancho Mínimo Media Query
Móvil 0px - 767px Por defecto (mobile first)
Tablet 768px+ @media (min-width: 768px)
Desktop 1024px+ @media (min-width: 1024px)
Large Desktop 1440px+ @media (min-width: 1440px)

1. Media Queries Básicas

Las media queries permiten aplicar estilos CSS diferentes según las características del dispositivo.

/* Mobile First: Estilos base para móvil */ .container { padding: 16px; font-size: 14px; } /* Tablet: 768px y más */ @media (min-width: 768px) { .container { padding: 24px; font-size: 16px; } } /* Desktop: 1024px y más */ @media (min-width: 1024px) { .container { padding: 32px; font-size: 18px; } } /* Large Desktop: 1440px y más */ @media (min-width: 1440px) { .container { padding: 40px; max-width: 1200px; margin: 0 auto; } }
Mobile First: Es la mejor práctica moderna. Define estilos base para móvil y usa min-width para agregar complejidad en pantallas más grandes.

5. Tipografía Responsive con clamp()

La función clamp() permite crear tipografía fluida sin media queries.

Este texto se escala automáticamente entre 1rem y 1.5rem usando clamp(1rem, 3vw, 1.5rem). Cambia el tamaño de la ventana para verlo en acción.
/* Tipografía fluida con clamp() */ h1 { font-size: clamp(1.5rem, 5vw, 3rem); /* mínimo: 1.5rem, ideal: 5vw, máximo: 3rem */ } p { font-size: clamp(1rem, 2.5vw, 1.25rem); } /* Sin media queries - se adapta automáticamente */
Ventaja de clamp(): Elimina la necesidad de múltiples media queries para ajustar tamaños de fuente. El texto escala suavemente entre mínimo y máximo.

6. Media Queries Avanzadas

Orientación del Dispositivo

Esta caja cambia de color según la orientación de tu dispositivo. Verde en landscape (horizontal), amarillo en portrait (vertical).
/* Orientación horizontal */ @media (orientation: landscape) { .elemento { background-color: green; } } /* Orientación vertical */ @media (orientation: portrait) { .elemento { background-color: yellow; } }

Preferencia de Modo Oscuro

Esta caja respeta la preferencia de modo oscuro/claro del sistema operativo.
/* Modo claro (por defecto) */ @media (prefers-color-scheme: light) { body { background-color: white; color: #2c3e50; } } /* Modo oscuro */ @media (prefers-color-scheme: dark) { body { background-color: #2c3e50; color: white; } }

Preferencia de Movimiento Reducido

/* Respetar preferencia de movimiento reducido (accesibilidad) */ @media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } } /* Usuario prefiere animaciones */ @media (prefers-reduced-motion: no-preference) { .elemento { transition: all 0.3s ease; } }

Resolución de Pantalla (Retina)

/* Pantallas de alta resolución (Retina) */ @media (min-resolution: 2dppx) { .logo { background-image: url('logo@2x.png'); } } /* O usando -webkit- para compatibilidad */ @media (-webkit-min-device-pixel-ratio: 2) { .logo { background-image: url('logo@2x.png'); } }

7. Container Queries (CSS Moderno)

Container queries permiten que los estilos respondan al tamaño del contenedor padre en lugar del viewport. Más flexible que media queries para componentes.

Container Query Demo

Cambia el tamaño de la ventana. Este card se reorganiza basándose en el tamaño de su contenedor, no del viewport.

/* Definir el contenedor */ .container { container-type: inline-size; /* o container-name: sidebar; para nombrarlo */ } /* Query basada en el tamaño del contenedor */ @container (min-width: 400px) { .card { display: flex; gap: 16px; } } @container (min-width: 600px) { .card { font-size: 1.2rem; } }
Soporte de Navegadores: Container queries son una característica moderna. Verifica la compatibilidad en caniuse.com antes de usar en producción.

8. Imágenes Responsive

/* Imagen responsive básica */ img { max-width: 100%; height: auto; display: block; } /* Responsive con picture element (HTML) */ <picture> <source media="(min-width: 1024px)" srcset="large.jpg"> <source media="(min-width: 768px)" srcset="medium.jpg"> <img src="small.jpg" alt="Descripción"> </picture> /* Object-fit para controlar el ajuste */ .image-container img { width: 100%; height: 300px; object-fit: cover; /* cover, contain, fill, none */ }

9. Rangos de Media Queries

/* Entre 768px y 1024px solamente */ @media (min-width: 768px) and (max-width: 1023px) { .elemento { /* Estilos solo para tablets */ } } /* Múltiples condiciones */ @media (min-width: 768px) and (orientation: landscape) { .elemento { /* Tablet en modo landscape */ } } /* Sintaxis moderna de rangos (CSS4) */ @media (768px <= width <= 1024px) { .elemento { /* Más legible */ } } /* Operador OR con coma */ @media (max-width: 767px), (min-width: 1440px) { .elemento { /* Móvil O Large Desktop */ } }

Mejores Prácticas Responsive

  • ✓ Usa enfoque Mobile First (min-width en lugar de max-width)
  • ✓ Define breakpoints basados en contenido, no en dispositivos específicos
  • ✓ Usa unidades relativas (rem, em, %, vw, vh) en lugar de px fijos
  • ✓ Aprovecha clamp() para tipografía y espaciado fluidos
  • ✓ Prueba en dispositivos reales, no solo en emuladores
  • ✓ Usa Grid y Flexbox para layouts flexibles
  • ✓ Optimiza imágenes para diferentes tamaños con picture/srcset
  • ✓ Considera container queries para componentes reutilizables
  • ✓ Respeta prefers-reduced-motion para accesibilidad
  • ✓ Incluye siempre el meta viewport tag

10. Estrategia de Breakpoints

Framework Breakpoints
Bootstrap 576px, 768px, 992px, 1200px, 1400px
Tailwind CSS 640px, 768px, 1024px, 1280px, 1536px
Material Design 600px, 960px, 1280px, 1920px
Recomendación General 768px (tablet), 1024px (desktop), 1440px (large)
Consejo: No te cases con breakpoints específicos. Ajusta según las necesidades de tu contenido. Si tu diseño se rompe a 900px, ese es tu breakpoint.

11. Estilos de Impresión

/* Estilos específicos para impresión */ @media print { /* Ocultar elementos innecesarios */ nav, .sidebar, .no-print { display: none !important; } /* Ajustar colores para impresión */ body { background: white; color: black; } /* Evitar saltos de página dentro de elementos */ .section, .card { page-break-inside: avoid; } /* Mostrar URLs de enlaces */ a[href]::after { content: " (" attr(href) ")"; } /* Ajustar tamaños de fuente */ body { font-size: 12pt; line-height: 1.5; } }
Tip: Prueba los estilos de impresión con Ctrl+P o usando DevTools (F12 → Rendering → Emulate CSS media type → print).
