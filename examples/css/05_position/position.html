Position Property

Controlando el posicionamiento de elementos

¿Qué es la propiedad Position?

La propiedad position especifica el tipo de posicionamiento de un elemento. Determina cómo se ubica en el documento y cómo interactúa con otros elementos. Las propiedades top, right, bottom y left solo funcionan cuando position está definido.

Importante: El valor por defecto es static, donde los elementos siguen el flujo normal del documento.
Valor Descripción Comportamiento
static Posicionamiento normal Flujo normal, ignora top/right/bottom/left
relative Relativo a su posición original Offset desde su posición normal, mantiene espacio
absolute Relativo al ancestro posicionado Removido del flujo, no ocupa espacio
fixed Relativo al viewport Permanece fijo al hacer scroll
sticky Híbrido relative/fixed Relativo hasta cierto punto, luego fijo

position: static (por defecto)

position: static es el valor por defecto. Los elementos se posicionan según el flujo normal del documento. Las propiedades top, right, bottom y left no tienen efecto.

Static Box

El elemento static sigue el flujo normal del documento.

.elemento { position: static; /* Valor por defecto */ top: 20px; /* NO tiene efecto */ left: 30px; /* NO tiene efecto */ }

position: relative

position: relative posiciona el elemento relativo a su posición original en el flujo del documento. El espacio original se mantiene reservado.

Box Original
Relative Box
(top: 20px, left: 30px)
Box Siguiente
.elemento { position: relative; top: 20px; /* Desplaza 20px hacia abajo */ left: 30px; /* Desplaza 30px hacia la derecha */ } /* El espacio original se mantiene vacío Otros elementos no ocupan ese espacio */
Uso común: Ajustes sutiles de posición, contexto de posicionamiento para elementos absolute hijos, animaciones.

position: absolute

position: absolute posiciona el elemento relativo a su ancestro posicionado más cercano (cualquier ancestro con position diferente a static). Si no existe, se posiciona relativo al documento. El elemento se remueve del flujo normal.

Box Normal
Absolute Box
(top: 50px, right: 20px)
Box Siguiente

Nota: El absolute box se posiciona relativo al contenedor con borde punteado (position: relative)

/* Contenedor padre */ .contenedor { position: relative; /* Crea contexto de posicionamiento */ } /* Elemento hijo */ .elemento { position: absolute; top: 50px; /* 50px desde el top del contenedor */ right: 20px; /* 20px desde el right del contenedor */ }
Importante: Los elementos absolute se remueven del flujo, no ocupan espacio, y otros elementos actúan como si no existieran.

position: fixed

position: fixed posiciona el elemento relativo al viewport (ventana del navegador). Permanece en la misma posición incluso al hacer scroll. Se remueve del flujo normal.

Ejemplo en vivo: Observa la caja roja en la esquina inferior derecha de tu pantalla. Es un elemento fixed que permanece visible al hacer scroll.
Fixed Box
Scroll para verlo
.elemento { position: fixed; bottom: 20px; /* 20px desde el bottom del viewport */ right: 20px; /* 20px desde el right del viewport */ z-index: 1000; /* Encima de otros elementos */ }
Uso común: Headers fijos, botones de "volver arriba", chat widgets, notificaciones, menús de navegación fijos.

position: sticky

position: sticky es un híbrido entre relative y fixed. Se comporta como relative hasta que alcanza un umbral de scroll, entonces se comporta como fixed.

z-index y Stacking Context

La propiedad z-index controla el orden de apilamiento de elementos posicionados (non-static). Valores mayores aparecen encima de valores menores.

Demostración visual:

z-index: 1
z-index: 2
z-index: 3
.capa-1 { position: absolute; z-index: 1; /* Capa más baja */ } .capa-2 { position: absolute; z-index: 2; /* Capa media */ } .capa-3 { position: absolute; z-index: 3; /* Capa más alta */ } /* z-index solo funciona con elementos posicionados (position: relative, absolute, fixed, sticky) */
Nota: z-index solo funciona en elementos con position diferente a static. Los valores pueden ser negativos.

Ejemplos Prácticos

1. Tooltip con position: absolute

¡Soy un tooltip posicionado!
.tooltip-container { position: relative; /* Contexto para el tooltip */ } .tooltip-text { position: absolute; bottom: 125%; /* Arriba del botón */ left: 50%; transform: translateX(-50%); /* Centrar */ visibility: hidden; } .tooltip-container:hover .tooltip-text { visibility: visible; }

2. Modal con position: fixed

.modal-overlay { position: fixed; top: 0; left: 0; width: 100%; height: 100%; background-color: rgba(0, 0, 0, 0.7); z-index: 999; /* Encima de todo */ } .modal-content { position: relative; background: white; padding: 2rem; border-radius: 10px; }

Mejores Prácticas

  • ✓ Usa position: relative en el contenedor padre de elementos absolute
  • ✓ Usa position: fixed para elementos que deben permanecer visibles al scroll
  • ✓ Usa position: sticky para headers y navegación contextual
  • ✓ Usa z-index con moderación, valores entre 0-1000 suelen ser suficientes
  • ✓ Recuerda que absolute y fixed remueven el elemento del flujo normal
  • ✓ Combina position con transform para centrado perfecto
