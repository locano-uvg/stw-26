Funciones Matemáticas en CSS

CSS moderno ofrece potentes funciones matemáticas que permiten crear layouts dinámicos y responsive sin necesidad de JavaScript.

Función Sintaxis Descripción
calc() calc(expresión) Realiza cálculos matemáticos
clamp() clamp(min, ideal, max) Limita un valor entre mínimo y máximo
min() min(valor1, valor2, ...) Retorna el valor más pequeño
max() max(valor1, valor2, ...) Retorna el valor más grande

1. calc(): Cálculos Dinámicos

La función calc() permite realizar operaciones matemáticas mezclando diferentes unidades (px, %, rem, vw, etc.).

Esta caja tiene width: calc(100% - 40px)
/* Operaciones básicas: +, -, *, / */ .elemento { width: calc(100% - 40px); /* Ancho completo menos 40px */ height: calc(100vh - 80px); /* Altura viewport menos 80px */ margin: calc(1rem + 2px); /* Sumar diferentes unidades */ font-size: calc(1rem + 0.5vw); /* Tipografía responsive */ } /* Espacios obligatorios con + y - */ .correcto { width: calc(100% - 20px); } .incorrecto { width: calc(100%-20px); } /* ¡ERROR! */ /* No requiere espacios con * y / */ .elemento { width: calc(100%/3); /* Funciona */ padding: calc(2rem * 1.5); /* Funciona */ }

Ejemplo Práctico: Layout con Sidebar

Sidebar

Ancho fijo: 250px

Contenido Principal

Ancho: calc(100% - 250px - 16px)

Se resta el ancho del sidebar y el gap.

/* Layout con sidebar de ancho fijo */ .layout { display: flex; gap: 16px; } .sidebar { width: 250px; } .main { width: calc(100% - 250px - 16px); /* Total - sidebar - gap */ }
Caso de uso común: calc() es perfecto para layouts que combinan elementos de tamaño fijo con elementos flexibles.

2. clamp(): Valores Fluidos con Límites

clamp() define un valor que crece/decrece según el viewport, pero nunca excede los límites mínimo y máximo.

Este texto usa: font-size: clamp(1rem, 3vw, 2rem)
Esta caja usa: width: clamp(200px, 50%, 600px)
Cambia el tamaño de la ventana para verlo en acción
/* Sintaxis: clamp(mínimo, ideal, máximo) */ h1 { font-size: clamp(1.5rem, 5vw, 3rem); /* Mínimo: 1.5rem Ideal: 5vw (crece con el viewport) Máximo: 3rem */ } /* Tipografía fluida sin media queries */ p { font-size: clamp(1rem, 2.5vw, 1.25rem); } /* Espaciado responsive */ .container { padding: clamp(1rem, 5vw, 3rem); } /* Ancho de contenedor */ .wrapper { width: clamp(300px, 90%, 1200px); margin: 0 auto; }
Ventaja principal: clamp() elimina la necesidad de múltiples media queries para ajustar tamaños. El valor escala suavemente entre mínimo y máximo.

3. min(): El Valor Más Pequeño

min() retorna el menor valor de una lista. Útil para establecer límites máximos.

width: min(500px, 100%)
Nunca excede 500px, pero se adapta en pantallas pequeñas
/* El valor más pequeño gana */ .elemento { width: min(500px, 100%); /* En pantallas grandes: 500px En pantallas pequeñas: 100% */ } /* Equivalente a */ .elemento { width: 100%; max-width: 500px; } /* Con múltiples valores */ .elemento { width: min(800px, 90%, 70vw); /* Usa el más pequeño de los tres */ } /* Espaciado que no excede cierto valor */ .grid { gap: min(2rem, 5vw); }

4. max(): El Valor Más Grande

max() retorna el mayor valor de una lista. Útil para establecer límites mínimos.

width: max(300px, 50%)
Nunca es menor a 300px
/* El valor más grande gana */ .elemento { width: max(300px, 50%); /* En pantallas grandes: 50% En pantallas pequeñas: 300px (mínimo) */ } /* Equivalente a */ .elemento { width: 50%; min-width: 300px; } /* Asegurar tamaño mínimo de fuente */ p { font-size: max(16px, 1rem); } /* Padding que nunca es muy pequeño */ .card { padding: max(1rem, 3vw); }

5. aspect-ratio: Mantener Proporciones

La propiedad aspect-ratio mantiene una relación de aspecto específica automáticamente.

aspect-ratio: 16 / 9
1:1
1:1
1:1
/* Mantener proporción 16:9 (videos) */ .video-container { aspect-ratio: 16 / 9; width: 100%; } /* Cuadrado perfecto */ .square { aspect-ratio: 1; width: 200px; /* Altura será automáticamente 200px */ } /* Proporción 4:3 (imágenes clásicas) */ .thumbnail { aspect-ratio: 4 / 3; } /* Con object-fit para control de contenido */ .image-wrapper { aspect-ratio: 16 / 9; } .image-wrapper img { width: 100%; height: 100%; object-fit: cover; }
Antes de aspect-ratio: Se usaba el "padding-bottom hack". Ahora aspect-ratio es mucho más simple y limpio.

6. object-fit: Control de Imágenes y Videos

object-fit controla cómo el contenido de un elemento reemplazado (img, video) se ajusta a su contenedor.

/* Valores de object-fit */ img { width: 300px; height: 200px; object-fit: cover; /* Cubre el área, puede recortar */ } .contain { object-fit: contain; } /* Cabe completo, puede haber espacio */ .cover { object-fit: cover; } /* Cubre el área, mantiene proporción */ .fill { object-fit: fill; } /* Rellena (puede distorsionar) */ .none { object-fit: none; } /* Tamaño original (puede recortar) */ .scale-down { object-fit: scale-down; } /* El menor entre none y contain */ /* Posicionar el contenido */ img { object-fit: cover; object-position: center; /* top, bottom, left, right, center */ object-position: 50% 50%; /* Coordenadas */ object-position: top right; /* Esquina superior derecha */ }
Caso de uso: object-fit: cover es perfecto para thumbnails y galerías donde necesitas tamaños uniformes sin distorsión.

7. backdrop-filter: Efectos de Glass Morphism

backdrop-filter aplica efectos gráficos al área detrás del elemento, creando efectos de vidrio esmerilado.

Glass Morphism

backdrop-filter: blur(10px)

Efecto de vidrio esmerilado moderno

/* Efecto de vidrio esmerilado */ .glass-card { background: rgba(255, 255, 255, 0.1); backdrop-filter: blur(10px); -webkit-backdrop-filter: blur(10px); /* Safari */ border: 1px solid rgba(255, 255, 255, 0.2); border-radius: 12px; } /* Combinando múltiples filtros */ .advanced-glass { backdrop-filter: blur(10px) saturate(180%); } /* Modal con fondo desenfocado */ .modal-overlay { backdrop-filter: blur(5px) brightness(0.7); } /* Navbar translúcida */ .navbar { background: rgba(255, 255, 255, 0.8); backdrop-filter: blur(20px); }
Rendimiento: backdrop-filter puede ser costoso en términos de rendimiento. Úsalo con moderación en elementos pequeños.

La propiedad filter aplica efectos gráficos como desenfoque, brillo, contraste, etc.

/* Filtros individuales */ img { filter: blur(5px); /* Desenfoque */ filter: brightness(1.5); /* Más brillante */ filter: contrast(200%); /* Más contraste */ filter: grayscale(100%); /* Blanco y negro */ filter: hue-rotate(90deg); /* Rotar colores */ filter: saturate(200%); /* Más saturación */ filter: sepia(100%); /* Efecto sepia */ filter: invert(100%); /* Invertir colores */ filter: opacity(50%); /* Transparencia */ } /* Combinar múltiples filtros */ .vintage { filter: sepia(50%) contrast(1.2) brightness(0.9); } /* Hover effects */ img:hover { filter: brightness(1.2) saturate(1.3); transition: filter 0.3s ease; } /* Drop shadow (sombra que sigue la forma) */ .icon { filter: drop-shadow(2px 2px 4px rgba(0,0,0,0.3)); }

Ejemplo Práctico Completo

Combinando múltiples funciones modernas en un componente real.

Card Moderna

Este componente usa:

  • clamp() para ancho responsive
  • aspect-ratio para la imagen
  • object-fit para ajustar la imagen
/* Card con funciones modernas */ .modern-card { /* Ancho fluido con límites */ width: clamp(300px, 80%, 600px); margin: 0 auto; /* Espaciado responsive */ padding: clamp(1rem, 3vw, 2rem); background-color: white; border-radius: 12px; box-shadow: 0 4px 8px rgba(0,0,0,0.15); } .modern-card img { width: 100%; /* Mantener proporción 16:9 */ aspect-ratio: 16 / 9; /* Ajustar la imagen al contenedor */ object-fit: cover; border-radius: 8px; } .modern-card h3 { /* Tipografía fluida */ font-size: clamp(1.25rem, 4vw, 1.75rem); /* Espaciado calculado */ margin: calc(1rem + 0.5vw) 0 0.5rem; }

Mejores Prácticas

  • ✓ Usa clamp() para tipografía y espaciado fluidos sin media queries
  • ✓ calc() es perfecto para layouts que mezclan unidades fijas y relativas
  • ✓ min() para establecer máximos, max() para establecer mínimos
  • ✓ aspect-ratio simplifica el mantenimiento de proporciones
  • ✓ object-fit: cover para imágenes de tamaño uniforme en galerías
  • ✓ backdrop-filter con moderación (costo de rendimiento)
  • ✓ Combina funciones para crear componentes verdaderamente responsive
  • ✓ Verifica soporte de navegadores para funciones muy nuevas

Soporte de Navegadores

Función Soporte Notas
calc() Excelente (IE9+) Muy maduro, úsalo sin preocupación
clamp() Muy bueno (2020+) No funciona en IE, bien en otros
min() / max() Muy bueno (2020+) Similar a clamp()
aspect-ratio Bueno (2021+) Usa fallback para navegadores antiguos
object-fit Excelente (2015+) No en IE, bien en navegadores modernos
backdrop-filter Bueno (con prefijo) Requiere -webkit- en Safari
filter Excelente (2013+) Amplio soporte
Recomendación: Verifica siempre en caniuse.com antes de usar funciones nuevas en producción.
