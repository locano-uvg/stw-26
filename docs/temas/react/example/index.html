Instalar React desde 0

Tres formas de configurar un proyecto React paso a paso. El objetivo es que veas las diferencias entre cada enfoque y puedas copiar el código para probarlo tú mismo.

Forma 1 · CDN Forma 2 · npm Forma 3 · Vite
00

¿Qué vamos a ver?

Una misma aplicación React (un componente que muestra "¡Hola React!") configurada de tres maneras distintas. Cada forma agrega más herramientas y complejidad, pero también más poder.

Recuerda: React es solo una librería de JavaScript. No es un framework completo ni necesita herramientas mágicas. Las "tres formas" son simplemente distintas maneras de cargar esa librería en el navegador.
FormaResumenIdeal para
CDNCargar React desde una URL en un HTML simple.Demos, aprender lo básico.
npmInstalar React como dependencia y configurar todo a mano.Entender qué hace cada pieza.
VitePlantilla oficial que prepara todo en un solo comando.Proyectos reales.
01

Requisitos previos

Para las formas 2 y 3 necesitas Node.js y npm instalados. Para la forma 1 (CDN), basta con un navegador.

1 Verifica que tengas Node.js y npm
Abre la terminal y ejecuta:
bash
node -v
npm -v
Deberías ver versiones tipo v18+ o superior. Si no, descarga Node desde nodejs.org.
Tip: Recomendamos VS Code como editor y la extensión Live Server para abrir el HTML de la forma 1 con recarga automática.
02

Forma 1 · Instalación con CDN sin instalar nada

La forma más rápida de ver React funcionando. Cargamos la librería desde una URL pública (unpkg) y opcionalmente Babel para poder escribir JSX directamente en el navegador.

1 Crear los archivos
Crea una carpeta nueva con dos archivos vacíos:
bash
mkdir react-cdn
cd react-cdn
touch index.html main.js
2 Configurar el index.html
Carga React, ReactDOM y Babel desde unpkg. El div#root es donde React montará la aplicación.
html
<!doctype html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>React con CDN</title>
  </head>
  <body>
    <div id="root"></div>

    <!-- React desde CDN -->
    <script crossorigin src="https://unpkg.com/react@18/umd/react.development.js"></script>
    <script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>

    <!-- Babel para usar JSX en el navegador -->
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>

    <!-- Nuestro código (type="text/babel" para que Babel lo procese) -->
    <script type="text/babel" src="main.js"></script>
  </body>
</html>
3 Escribir el componente en main.js
React no se importa porque ya está disponible globalmente gracias a los scripts del CDN.
jsx
const App = () => {
  return <h1 style={{ color: "steelblue" }}>¡Hola React con CDN!</h1>;
};

const root = ReactDOM.createRoot(document.getElementById("root"));
root.render(<App />);
4 Abrir en el navegador
Solo abre index.html directamente con doble click, o usa Live Server en VS Code.
Advertencia: Babel en el navegador es muy lento y nunca debe usarse en producción. Esta forma sirve para aprender y demos, no para apps reales.

Ventajas

  • No requiere instalación
  • Bueno para demos rápidos
  • Útil para enseñar conceptos
  • Funciona en cualquier servidor estático

Desventajas

  • Babel en navegador es muy lento
  • No hay módulos ni imports
  • No optimiza para producción
  • No hay hot reload
03

Forma 2 · Instalación con npm configuración manual

Instalamos React como dependencia real y configuramos un bundler (Vite) a mano para entender qué hace cada pieza. Esta es la forma "educativa" — en proyectos reales usarás la Forma 3.

1 Crear el proyecto y package.json
Inicializa npm en una carpeta nueva:
bash
mkdir react-npm
cd react-npm
npm init -y
Esto genera un package.json con la configuración base.
2 Instalar React y ReactDOM
Estas son las dos librerías que componen React:
bash
npm install react react-dom
Aparecerá la carpeta node_modules/, un package-lock.json, y las dependencias en package.json.
3 Instalar el bundler (Vite como dev dependency)
React no se ejecuta solo en el navegador: necesita un bundler que empaquete los módulos y compile JSX. Vamos a usar Vite, pero instalado a mano.
bash
npm install --save-dev vite @vitejs/plugin-react
4 Configurar Vite
Crea vite.config.js en la raíz:
javascript
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";

export default defineConfig({
  plugins: [react()],
});
5 Crear index.html y main.jsx
Vite usa index.html como punto de entrada (en la raíz, no dentro de public/):
html
<!doctype html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>React con npm</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/main.jsx"></script>
  </body>
</html>
Y main.jsx con el componente:
jsx
import React from "react";
import ReactDOM from "react-dom/client";

const App = () => {
  return <h1 style={{ color: "steelblue" }}>¡Hola React con npm!</h1>;
};

const root = ReactDOM.createRoot(document.getElementById("root"));
root.render(<App />);
6 Agregar scripts en package.json
Edita la sección "scripts":
json
"scripts": {
  "dev": "vite",
  "build": "vite build",
  "preview": "vite preview"
}
7 Levantar el servidor de desarrollo
bash
npm run dev
Abre la URL que aparezca (por defecto http://localhost:5173).
¿Por qué hicimos todo esto a mano? Para que veas que un proyecto React real necesita: la librería (react), un renderer (react-dom), y un bundler (vite) que sepa cómo procesar JSX y módulos. La Forma 3 hace exactamente lo mismo en un solo comando.

Ventajas

  • Entiendes qué hace cada dependencia
  • Control total de la configuración
  • JSX, módulos y hot reload
  • Listo para producción

Desventajas

  • Más pasos manuales
  • Más fácil equivocarse
  • Hay que crear los archivos uno por uno
  • Reinventas lo que la Forma 3 ya hace
04

Forma 3 · Instalación con Vite recomendado

La forma estándar para proyectos reales. La plantilla oficial de Vite hace todos los pasos de la Forma 2 automáticamente, en un solo comando.

1 Crear el proyecto
bash
npm create vite@latest mi-app -- --template react
Si te lo pide de forma interactiva, elige:
  • Project name: mi-app
  • Framework: React
  • Variant: JavaScript (o TypeScript)
2 Instalar dependencias
bash
cd mi-app
npm install
3 Ejecutar el proyecto
bash
npm run dev       # Servidor de desarrollo
npm run build     # Build de producción en /dist
npm run preview   # Previsualizar la build
4 Estructura típica del proyecto
Esto es lo que Vite genera por ti:
mi-app/ ├── node_modules/ ├── public/ ├── src/ │ ├── App.jsx │ ├── main.jsx │ └── index.css ├── index.html ├── package.json └── vite.config.js
Tip: Compara esta estructura con lo que armaste a mano en la Forma 2: ¡es exactamente lo mismo! Vite solo automatiza los pasos.

Ventajas

  • Todo configurado en un comando
  • Estructura estándar lista
  • Hot reload instantáneo
  • Optimizado para producción
  • Es el estándar actual

Desventajas

  • "Caja negra" si no entiendes lo previo
  • Trae archivos de ejemplo que hay que limpiar
  • Requiere Node y npm instalados
05

Comparación lado a lado

Las tres formas hacen funcionar React, pero con distintas capacidades y propósitos.

Característica CDN npm Vite
InstalaciónNingunaManualPlantilla automática
JSXCon Babel (lento)Sí, vía bundlerSí, listo
Hot reloadNoSíSí
Módulos / importsNoSíSí
Optimizado para producciónNoSíSí
Requiere NodeNoSíSí
Tiempo de setup~1 min~10 min~30 seg
Ideal paraDemos / aprenderEntender configuraciónProyectos reales
Conclusión: En clase usaremos las tres formas para entender la evolución. En tus proyectos reales, siempre usa Vite (Forma 3). Las otras dos te ayudan a entender qué pasa por debajo.
