01

Variables

Una variable es un espacio en memoria donde guardamos un valor. En JavaScript moderno usamos let y const.

Palabra clave Se puede reasignar Uso recomendado
const No Valores que no cambian (URL, IDs, configuracion)
let Si Valores que pueden cambiar (contadores, estado)
var Si Evitar — comportamiento impredecible de scope
JavaScript 
// const: el valor NO puede cambiar
const nombre = "Ana";
const edad   = 20;
const activo = true;

// let: el valor SI puede cambiar
let puntaje = 0;
puntaje = 10;          // OK

// Tipos primitivos en JavaScript
const texto    = "Hola mundo";   // string
const numero   = 42;             // number
const booleano = false;          // boolean
const vacio    = null;           // null
let   sinValor;                   // undefined

02

El DOM — Document Object Model

El DOM es la representacion en memoria de tu pagina HTML. JavaScript puede leer y modificar cualquier elemento: texto, estilos, atributos y estructura.

Seleccionar elementos

  • getElementById — por id unico
  • querySelector — por selector CSS
  • querySelectorAll — lista de elementos

Modificar elementos

  • textContent — cambiar texto
  • innerHTML — insertar HTML
  • style — estilos en linea
  • classList — clases CSS
JavaScript 
// 1. Seleccionar un elemento
const titulo = document.querySelector("h1");
const boton  = document.getElementById("mi-boton");

// 2. Leer y modificar contenido
titulo.textContent = "Nuevo titulo";
titulo.style.color  = "#58a6ff";

// 3. Crear un elemento nuevo y agregarlo al DOM
const parrafo = document.createElement("p");
parrafo.textContent = "Hola, soy nuevo!";
parrafo.classList.add("mi-clase");
document.body.appendChild(parrafo);

// 4. Escuchar eventos
boton.addEventListener("click", () => {
  titulo.textContent = "Boton clickeado!";
});

03

Arreglos (Arrays)

Un arreglo es una lista ordenada de valores. Puede contener cualquier tipo de dato y se accede a cada elemento por su indice (empezando en 0).

JavaScript 
// Declarar un arreglo
const frutas = ["mango", "pera", "uva"];

// Acceder por indice (inicia en 0)
console.log(frutas[0]);  // "mango"
console.log(frutas[2]);  // "uva"

// Metodos esenciales
frutas.push("kiwi");                  // agrega al final
frutas.pop();                           // elimina el ultimo
frutas.includes("pera");               // true
frutas.indexOf("uva");                 // 2

// Recorrer con forEach
frutas.forEach((fruta) => {
  console.log(`Fruta: ${fruta}`);
});

// map — transforma cada elemento (nuevo arreglo)
const enMayusculas = frutas.map((f) => f.toUpperCase());

// filter — filtra elementos que cumplen una condicion
const numeros = [1, 2, 3, 4, 5, 6];
const pares   = numeros.filter((n) => n % 2 === 0); // [2,4,6]

04

Objetos

Un objeto agrupa datos relacionados usando pares clave: valor. Son la estructura de datos mas usada en JavaScript.

JavaScript 
// Crear un objeto literal
const estudiante = {
  nombre: "Carlos",
  edad: 21,
  activo: true,
  cursos: ["HTML", "CSS", "JS"],
};

// Acceder a propiedades
console.log(estudiante.nombre);          // "Carlos"
console.log(estudiante["edad"]);         // 21
console.log(estudiante.cursos[0]);       // "HTML"

// Modificar y agregar propiedades
estudiante.edad     = 22;
estudiante.carrera  = "Informatica";

// Objeto dentro de objeto (anidado)
const perfil = {
  usuario: "carlos_uvg",
  datos: {
    nombre: "Carlos",
    pais: "Guatemala",
  },
};
console.log(perfil.datos.pais);           // "Guatemala"

05

JSON — JavaScript Object Notation

JSON es el formato estandar para intercambiar datos en la web. Parece un objeto de JavaScript, pero es texto plano: las claves van entre comillas dobles.

JSON (texto plano) 
{
  "nombre": "Lucia",
  "edad":   23,
  "activo": true,
  "cursos": ["JS", "React"]
}
JavaScript 
// JSON → Objeto JS
const texto = '{"nombre":"Lucia","edad":23}';
const obj   = JSON.parse(texto);
console.log(obj.nombre);   // "Lucia"

// Objeto JS → JSON (para enviar)
const json = JSON.stringify(obj);
console.log(json);
// '{"nombre":"Lucia","edad":23}'

06

Destructuring

El destructuring te permite extraer valores de objetos o arreglos en variables individuales con una sintaxis mas limpia.

JavaScript — Destructuring de objeto 
const usuario = {
  nombre: "Sofia",
  edad:   22,
  pais:   "Guatemala",
};

// Sin destructuring — verboso
const nombre = usuario.nombre;
const edad   = usuario.edad;

// Con destructuring — limpio
const { nombre, edad, pais } = usuario;
console.log(nombre);  // "Sofia"
console.log(pais);    // "Guatemala"

// Alias: renombrar al extraer
const { nombre: alias } = usuario;
console.log(alias);   // "Sofia"

// Valor por defecto
const { rol = "estudiante" } = usuario;
console.log(rol);     // "estudiante" (no existia en el objeto)

// Destructuring de arreglo
const colores = ["rojo", "verde", "azul"];
const [primero, segundo] = colores;
console.log(primero);  // "rojo"

// Muy util con APIs: extraer solo lo que necesitas
const { name, email } = respuestaAPI;  // ignora el resto

07

Arrow Functions

Las arrow functions son una sintaxis mas corta para escribir funciones. Se usan constantemente en JavaScript moderno, especialmente con map, filter y fetch.

JavaScript 
// Funcion tradicional (declaration)
function saludar(nombre) {
  return `Hola, ${nombre}!`;
}

// Funcion expresion
const saludar = function(nombre) {
  return `Hola, ${nombre}!`;
};

// Arrow function — equivalente
const saludar = (nombre) => {
  return `Hola, ${nombre}!`;
};

// Arrow function — retorno implicito (una sola expresion)
const saludar = (nombre) => `Hola, ${nombre}!`;

// Sin parametros
const ahora = () => new Date().toLocaleTimeString();

// Con arrays — muy comun
const nums    = [1, 2, 3, 4];
const dobles  = nums.map((n) => n * 2);        // [2,4,6,8]
const mayores = nums.filter((n) => n > 2);     // [3,4]

08

Consumir APIs con Fetch

Una API (Application Programming Interface) expone datos que tu pagina puede solicitar. fetch() es la funcion nativa del navegador para hacer esas peticiones de forma asincrona.

Asincronia en 30 segundos: JavaScript ejecuta codigo linea por linea, pero fetch hace una peticion a internet que tarda tiempo. Para no "congelar" el navegador usamos async/await: le decimos al codigo que espere la respuesta antes de continuar.
JavaScript — Patron completo 
// async: marca la funcion como asincrona
async function obtenerUsuarios() {
  try {
    // await: espera la respuesta de la API
    const respuesta = await fetch("https://jsonplaceholder.typicode.com/users");

    // Convertir el cuerpo JSON a objeto JS
    const usuarios = await respuesta.json();

    // Usar los datos: mostrar en el DOM
    usuarios.forEach((u) => {
      const { name, email } = u;          // destructuring!
      const tarjeta = document.createElement("div");
      tarjeta.textContent = `${name} — ${email}`;
      document.getElementById("lista").appendChild(tarjeta);
    });

  } catch (error) {
    // Si algo falla (sin internet, error 404, etc.)
    console.error("Error:", error);
  }
}

obtenerUsuarios();   // llamar la funcion
