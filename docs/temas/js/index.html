¿Qué es el Backend?

Modelo Cliente — Servidor

Cuando visitas un sitio web, tu navegador (cliente) le solicita información a un servidor.

El servidor la procesa y te responde.

¿Dónde vive el código?

Frontend Backend
Navegador del usuario Servidor remoto
HTML / CSS / JS en el browser Node.js / Python / Go / Java…
Lo que el usuario ve Lo que el usuario NO ve

¿Qué hace el Backend?

  • Recibe solicitudes HTTP del cliente.
  • Ejecuta la lógica de negocio.
  • Consulta o modifica bases de datos.
  • Devuelve una respuesta (JSON, HTML, archivos…).

Analogía: Restaurante

  • Tú = Cliente (navegador)
  • Menú = Documentación de la API
  • Camarero = API (intermediario)
  • Cocina = Backend (servidor)
  • Comida = Respuesta con datos

Ciclo de una solicitud web


  [Navegador]  ──── HTTP Request ────  [Servidor]
                                              │
                                        Lógica + DB
                                              │
  [Navegador]  ─── HTTP Response ───  [Servidor]

El backend procesa, el frontend presenta.

JavaScript

Un lenguaje, dos mundos

¿Qué es JavaScript?

  • Creado en 1995 para ejecutarse en navegadores.
  • Lenguaje interpretado (no compilado).
  • Hoy es el único lenguaje que corre de forma nativa en el navegador.
  • Desde 2009, también corre en el servidor gracias a Node.js.

JS en el Frontend vs el Backend

Frontend (Navegador) Backend (Servidor)
Manipula el DOM Responde solicitudes HTTP
Maneja eventos del usuario Accede a bases de datos
Corre en el browser Corre en Node.js

Un mismo lenguaje que puedes usar en ambos lados del stack.

Características

  • Variables y tipos de datos.
  • Ejecución de operaciones y lógica.
  • Funciones y módulos.
  • Programación asíncrona (callbacks, Promises, async/await).

Fundamentos de JavaScript

Que necesitas para escribir código backend

Variables

  • Nombres que almacenan datos en memoria.
  • Usamos let, const y var.
  • Preferir let y const por su alcance de bloque.

Ejemplo:


let nombre = "Juan";
const PUERTO = 3000;
var edad = 25;        // evitar — alcance de función

const no puede reasignarse. let sí puede cambiar.

Tipos de Datos

JavaScript tiene 7 tipos de datos primitivos.

Para encontrar el tipo usamos typeof.

Condicionales

Ejecutan código según una condición.


let statusCode = 404;

if (statusCode === 200) {
  console.log("OK");
} else if (statusCode === 404) {
  console.log("Not Found");
} else {
  console.log("Error del servidor");
}

Estructura básica

  • Semicolons — opcionales pero recomendados.
  • Statements — instrucciones.
  • Comentarios — // linea y /* bloque */.
  • Variables — let / const.

Node.js

¿Qué es Node.js?

  • Entorno de ejecución de JS fuera del navegador.
  • Basado en el motor V8 de Google Chrome.
  • Modelo de eventos no bloqueante (asíncrono).
  • Ideal para servidores web, APIs, CLI tools.

# servidor.py
from http.server import HTTPServer, BaseHTTPRequestHandler

class MiServidor(BaseHTTPRequestHandler):
    def do_GET(self):
        self.send_response(200)
        self.end_headers()
        self.wfile.write(b"Hola desde Python")

servidor = HTTPServer(("localhost", 8000), MiServidor)
print("Corriendo en http://localhost:8000")
servidor.serve_forever()

from http.server import HTTPServer, BaseHTTPRequestHandler

class MiServidor(BaseHTTPRequestHandler):
    def do_GET(self):
        self.send_response(200)
        self.send_header("Content-Type", "application/json")
        self.end_headers()

        datos = {"id": 1, "nombre": "Ana", "activo": True}

# app.py
from flask import Flask, jsonify, request

app = Flask(__name__)

# Lista en memoria (simula una base de datos)
usuarios = [
    {"id": 1, "nombre": "Ana"},
    {"id": 2, "nombre": "Luis"}
]

if __name__ == "__main__":
    app.run(port=8000, debug=True)

GET — Leer datos

El cliente pide información. El servidor la devuelve.


# GET /usuarios  → devuelve todos
@app.route("/usuarios", methods=["GET"])
def obtener_todos():
    return jsonify(usuarios)

# GET /usuarios/1  → devuelve uno
@app.route("/usuarios/<int:id>", methods=["GET"])
def obtener_uno(id):
    usuario = next((u for u in usuarios if u["id"] == id), None)
    if usuario:
        return jsonify(usuario)
    return jsonify({"error": "No encontrado"}), 404
            

# Respuesta: GET /usuarios
[{"id": 1, "nombre": "Ana"}, {"id": 2, "nombre": "Luis"}]

POST — Crear datos

El cliente envía datos nuevos. El servidor los guarda.


@app.route("/usuarios", methods=["POST"])
def crear():
    nuevo = request.json          # datos que envió el cliente
    usuarios.append(nuevo)
    return jsonify(nuevo), 201    # 201 Created
            

# El cliente envía (body JSON):
{"id": 3, "nombre": "Carlos"}

# El servidor responde:
{"id": 3, "nombre": "Carlos"}   ← con status 201

PUT — Actualizar datos

El cliente envía los datos nuevos de un recurso existente.


@app.route("/usuarios/<int:id>", methods=["PUT"])
def actualizar(id):
    for u in usuarios:
        if u["id"] == id:
            u.update(request.json)
            return jsonify(u)
    return jsonify({"error": "No encontrado"}), 404
            

# PUT /usuarios/1  con body:
{"nombre": "Ana González"}

# Respuesta:
{"id": 1, "nombre": "Ana González"}

DELETE — Eliminar datos

El cliente indica qué recurso borrar. El servidor lo elimina.


@app.route("/usuarios/<int:id>", methods=["DELETE"])
def eliminar(id):
    global usuarios
    antes = len(usuarios)
    usuarios = [u for u in usuarios if u["id"] != id]
    if len(usuarios) < antes:
        return jsonify({"mensaje": "Usuario eliminado"})
    return jsonify({"error": "No encontrado"}), 404
            

# DELETE /usuarios/2

# Respuesta:
{"mensaje": "Usuario eliminado"}

JavaScript en el Frontend

Ahora veamos JS en el navegador

¿Qué es el DOM?

  • Document Object Model (DOM)
  • Representación en árbol del documento HTML.
  • JS puede leerlo y modificarlo en tiempo real.
  • Solo existe en el navegador (no en Node.js).

Manipulación del DOM

  • Cada etiqueta HTML es un nodo del árbol.
  • Podemos acceder, crear, modificar o eliminar nodos.
  • Responde a eventos del usuario (click, input, scroll…).

Ejemplo: modificar contenido


document.getElementById("titulo").textContent =
  "¡Hola, JavaScript!";

Ejemplo: responder a un evento


document.querySelector("button")
  .addEventListener("click", function() {
    alert("¡Botón clickeado!");
  });

Acceso a Nodos del DOM

Métodos de acceso

Dos formas de llegar a un nodo:

  • A través de su nodo padre (recorrido).
  • Acceso directo por id, clase o selector.

getElementsByTagName

Obtiene todos los elementos con una etiqueta dada.


let parrafos = document.getElementsByTagName("p");
let primer_parrafo = parrafos[0];

getElementById

Obtiene el elemento con un id específico.


let titulo = document.getElementById("titulo");
console.log(titulo);

getElementsByClassName

Obtiene todos los elementos con una clase dada.


let elementos = document.getElementsByClassName("parrafo");
console.log(elementos);

querySelector / querySelectorAll

Selecciona usando sintaxis CSS.


let parrafo  = document.querySelector("p");         // primero
let parrafos = document.querySelectorAll("p");      // todos

Crear y eliminar nodos

Modificar nodos

  • textContent — texto plano.
  • innerHTML — HTML interno.
  • style — estilos inline.
  • setAttribute — atributos HTML.

Ejemplos de modificación


// Texto
document.getElementById("titulo").textContent = "¡Hola!";

// HTML interno
document.getElementById("titulo").innerHTML =
  "¡Hola!";

// Estilo
document.getElementById("titulo").style.color = "red";
