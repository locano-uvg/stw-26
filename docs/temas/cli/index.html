Comandos CLI Básicos

Comandos para trabajar en sistemas sin interfaz gráfica.

Navegación por Directorios

Entendiendo las Rutas en Linux

Todo comienza desde la raíz (/)

$ ls /
bin boot dev etc home lib ...

Las rutas se componen de / y nombres de directorios.

/home/usuario/documentos significa:

  • / = raíz
  • home = directorio dentro de raíz
  • usuario = directorio dentro de home
  • documentos = directorio dentro de usuario

pwd

Significado: Print Working Directory

Muestra la ruta actual del directorio.

$ pwd
/home/usuario

Útil para saber dónde estás antes de navegar.

ls

Significado: List Directory Contents

Lista archivos y carpetas en el directorio actual.

$ ls
documentos fotos descargas

Opciones útiles:

  • ls -l: Muestra detalles como permisos y tamaños.
  • ls -a: Incluye archivos ocultos.

Rutas: Absolutas vs Relativas

Ruta absoluta: Comienza desde la raíz (/)

$ cd /home/usuario/documentos

Ruta relativa: Desde tu ubicación actual

$ cd documentos

Si estás en /home/usuario, ambos comandos te llevan al mismo lugar.

Notaciones Especiales de Directorios

Notación Descripción
. Directorio actual
.. Directorio padre (un nivel arriba)
~ Directorio home del usuario
- Directorio anterior

cd

Significado: Change Directory

Cambia al directorio especificado.

$ cd documentos
$ pwd
/home/usuario/documentos

Ejemplos:

  • cd o cd ~: Ir al directorio home
  • cd ..: Subir un nivel
  • cd -: Volver al directorio anterior
  • cd /home/usuario/documentos: Ruta absoluta
  • cd ../descargas: Ruta relativa

Tip: Usa la tecla TAB para autocompletar nombres de directorios.

Troubleshooting: Errores Comunes con cd

No such file or directory

$ cd Documentos
bash: cd: Documentos: No such file or directory

Posibles causas:

  • Error de escritura (Linux es case-sensitive: Documentos ≠ documentos)
  • Ruta incorrecta
  • Falta el / inicial en rutas absolutas

Not a directory

$ cd archivo.txt
bash: cd: archivo.txt: Not a directory

Estás intentando entrar a un archivo, no a un directorio.

Manipulación de Archivos y Directorios

mkdir

Significado: Make Directory

Crea un nuevo directorio.

$ mkdir nueva_carpeta

touch

Crea un archivo vacío.

$ touch archivo.txt

cp

Significado: Copy

Copia un archivo o directorio.

$ cp archivo.txt copia_archivo.txt

mv

Significado: Move

Mueve o renombra un archivo.

$ mv archivo.txt carpeta/

rm

Significado: Remove

Elimina archivos o carpetas.

$ rm archivo.txt

Eliminar carpetas con contenido:

$ rm -r carpeta

Visualización de Contenido

cat

Muestra el contenido de un archivo.

$ cat archivo.txt

head

Muestra las primeras líneas de un archivo.

$ head archivo.txt

tail

Muestra las últimas líneas de un archivo.

$ tail archivo.txt

Permisos y Propietarios

chmod

Significado: Change Mode

Cambia los permisos de un archivo.

$ chmod 755 archivo.txt

Permisos comunes:

  • 755: Lectura, escritura y ejecución para el propietario; solo lectura y ejecución para otros.
  • 644: Lectura y escritura para el propietario; solo lectura para otros.
  • 777: Lectura, escritura y ejecución para todos.

chown

Significado: Change Owner

Cambia el propietario de un archivo.

$ chown usuario archivo.txt
