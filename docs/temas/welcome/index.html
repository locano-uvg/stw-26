Descripción del Curso

¿Qué es este curso?

Este curso está diseñado para introducirte en el mundo de los sistemas y tecnologías web modernas.

Aprenderás los fundamentos necesarios para desarrollar aplicaciones web completas, desde el frontend hasta el backend.

Objetivos del Curso

  • Comprender los fundamentos de internet y la web
  • Dominar las tecnologías básicas: HTML, CSS y JavaScript
  • Aprender a trabajar con servidores web
  • Desarrollar aplicaciones web interactivas
  • Explorar frameworks modernos como React
  • Entender el desarrollo de APIs y servicios web
