¿Qué es un Servidor Web?

Hardware vs Software

  • Hardware: La máquina física donde se guardan los datos.
  • Software: El programa (Nginx, Apache) que "sirve" los archivos al navegador.

En este curso nos enfocamos en el Software.

El Ciclo de Vida de un Request

¿Qué pasa cuando entras a google.com?

  1. DNS Lookup: El navegador busca la IP del dominio.
  2. TCP Handshake: Se establece conexión.
  3. TLS Handshake: Se negocia la encriptación (HTTPS).
  4. HTTP Request: "Dame el index.html".
  5. Processing: El servidor busca el archivo o ejecuta código.
  6. HTTP Response: El servidor envía el archivo.

Arquitectura Moderna

graph LR A[Cliente / Navegador] -- HTTPS --> B[Reverse Proxy / Nginx] B -- HTTP --> C[App Server / Node.js] B -- HTTP --> D[App Server / Python] C --> E[(Base de Datos)] D --> E
El Reverse Proxy es el portero: maneja seguridad, SSL y balanceo de carga.

El Protocolo HTTP

La web funciona gracias al protocolo HTTP (Hypertext Transfer Protocol). Es una conversación simple:

  1. Cliente (Navegador): Envía una Petición (Request).
    "¡Hola! Quiero ver la página index.html"
  2. Servidor: Envía una Respuesta (Response).
    "Aquí tienes el archivo index.html" (o "No lo encuentro - Error 404")

HTTP Headers (Encabezados)

Son como la "etiqueta del envío" en un paquete postal. No son el contenido en sí, sino información sobre el contenido.

  • Headers del Cliente: Qué navegador usa, qué idiomas acepta, cookies.
  • Headers del Servidor: Qué tipo de archivo envía (HTML, imagen), cuánto pesa, cuándo expira.

Content-Type: text/html; charset=UTF-8
Server: nginx/1.18.0
Date: Mon, 27 Sep 2025 12:00:00 GMT

Seguridad Web: HTTPS

  • HTTP: Texto plano. Cualquiera en la red puede leer tus passwords.
  • HTTPS (TLS/SSL): Encriptado. Solo el cliente y el servidor pueden leerlo.
  • Certificados: Validan tu identidad. Hoy son gratis gracias a Let's Encrypt.

Antes de Instalar un Servidor

Para administrar un servidor web exitosamente, es necesario dominar:

  • La Terminal: Moverse entre carpetas, editar archivos de texto (nano/vim), permisos.
  • Redes Básicas: Entender qué es una Dirección IP y un Puerto (ej. puerto 80 para web).
  • DNS: Cómo un nombre de dominio (google.com) se convierte en una IP.

Servidores Web Existentes

Existen muchas opciones en el mercado:

  • Apache: El veterano, muy flexible y usado históricamente.
  • Nginx: Conocido por su alto rendimiento y velocidad. Muy popular hoy en día.
  • Caddy: Moderno, fácil de usar y con HTTPS automático por defecto.
  • IIS (Internet Information Services): La solución de Microsoft para Windows Server.

Herramientas Populares

Servidor Tipo Mejor Para...
Nginx Web Server / Proxy Producción, Alto Rendimiento, Static Files
Apache Web Server Hosting Compartido (.htaccess), Legacy
Caddy Web Server Moderno HTTPS Automático, Facilidad de uso
Node.js App Server Lógica de Negocio, APIs (No archivos estáticos)

Ejemplo Práctico: Local & Tunnel


# 1. Crear un servidor simple en tu compu
# Crea un archivo index.html con "Hola Mundo"
echo "
Hola Mundo desde mi Local
" > index.html

# 2. Levantar servidor (Python viene en Mac/Linux)
python3 -m http.server 8080

# 3. Exponerlo a internet con Ngrok
ngrok http 8080
¡Inténtalo! Ngrok te dará una URL pública (ej. https://xyz.ngrok.io) que funciona en cualquier parte del mundo.

Ejemplo Práctico: La Nube (Preview)

En un servidor real (Linux), haríamos esto:


# 1. Instalar Nginx
sudo apt update && sudo apt install nginx

# 2. Configurar Firewall (UFW)
sudo ufw allow 'Nginx Full'

# 3. Obtener Certificado SSL (HTTPS)
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d midominio.com
